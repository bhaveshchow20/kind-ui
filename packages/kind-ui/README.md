# kind-ui

Private, empty package scaffold for Kind UI. This package has no product API or runtime behavior yet. The working name does not imply npm ownership or an installation route.

From the repository root, run `npm ci` and `npm run check`. TypeScript emits ESM and declarations into `dist/`; generated files are not committed.

See the repository [README](../../README.md), [contribution guide](../../CONTRIBUTING.md), and [development direction](../../docs/development.md) before proposing implementation. Product dependencies and architecture remain open decisions.
