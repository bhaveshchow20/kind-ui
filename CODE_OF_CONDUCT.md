# Code of Conduct

Contributors and participants should be respectful, patient, and constructive. Focus feedback on the work, explain disagreements, and make room for people with different backgrounds and experience levels.

Harassment, discriminatory attacks, threats, sexual harassment, doxxing, and deliberate disclosure of another person's private information are not acceptable. These expectations apply in this repository's issues, pull requests, and other project-managed spaces.

If a concern arises, contact the repository owner through an existing private channel. If you do not have one, request a private contact route without posting sensitive details. The project does not currently have a separate moderation team or a guaranteed response time. Do not share another person's report publicly without their permission.

The repository owner may ask participants to change behavior, remove inappropriate project content, or restrict participation according to the situation and available platform permissions. Reports should be handled with care and only shared when necessary to address the concern.

This is an original, lightweight project policy for the pre-release repository. Review the reporting and moderation process before opening the project to broader participation.
