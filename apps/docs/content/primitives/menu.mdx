import { api } from "@/lib/primitives/menu";

Use menu items for actions, checkbox items for independent settings, and radio items for one choice within a group. Arrow keys navigate, typing finds an item, and Escape returns to the trigger. Keep forms and longer tasks in a Popover or Dialog.

## API reference

`Content` combines the portal, positioner and styled popup. Use the individual parts when you need to control their markup or mounting. Element parts also accept refs, native attributes and event handlers.
