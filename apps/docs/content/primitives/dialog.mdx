Use a dialog for a focused task that needs its own space. Compose `DialogTitle`, a useful description and a visible close action inside `DialogContent`. This example keeps draft changes separate until you save.

<PrimitiveExample id="dialog" />

`DialogContent` composes the portal, backdrop and popup. Use those parts directly for a custom layout. Keyboard focus stays inside a modal and returns to its trigger when it closes; Escape dismisses it.
