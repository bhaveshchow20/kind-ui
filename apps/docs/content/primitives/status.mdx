Use Status to identify a process or item state. Your application owns state changes, labels and announcements. Set `pulse` only while activity is happening; it respects reduced motion.

<PrimitiveExample id="status" />

`pending` uses a neutral dashed treatment, `inflight` uses info, `active` uses success, and `error` uses danger. A stable `role="status"` region can announce meaningful changes without moving focus.
