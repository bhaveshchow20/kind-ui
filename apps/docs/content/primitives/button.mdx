import { api } from "@/lib/primitives/button";

Use a Button for an action. Keep its label specific, and set `loading` while work is pending to prevent repeated activation. The built-in feedback respects reduced motion.

<PrimitiveExample id="button" />

Use `type="submit"` inside a form. For navigation, apply `buttonVariants()` to a semantic link. `shortcut` displays a hint; your application registers the shortcut.
