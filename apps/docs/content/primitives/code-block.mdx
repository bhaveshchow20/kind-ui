---
title: Code Block
description: Display code with line numbers, copy feedback and file downloads.
---

Give `CodeBlock` a source string and compose its header, actions and content when you need a custom label. Copy and download always use the original `code` string. Try the actions or toggle line wrapping below.

<PrimitiveExample id="code-block" />

For syntax highlighting, prepare `tokens` with your highlighter on the server and pass them alongside the matching `code`. The language label alone does not highlight source text.
