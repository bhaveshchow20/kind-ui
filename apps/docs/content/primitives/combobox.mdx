---
title: Combobox
description: Search a collection and select a value with an accessible input and popup.
---

Pass the available `items` to `Combobox`, then compose a labeled input and a list of matching values. Selection and search text have separate state. Type a teammate's name below, use the arrow keys to navigate, then press Enter to select.

<PrimitiveExample id="combobox" />

Use `itemToStringLabel` and `itemToStringValue` for custom object values. For remote results, control the search text and pass `filteredItems`; keep `ComboboxStatus` mounted for loading or error announcements.
