title: Table
description: Compose semantic data tables with copy, download and fullscreen actions.
---

Use native table parts for comparable rows and columns. Place the table in `TableViewport` for horizontal scrolling, and keep its actions inside `TableContainer`. The toolbar below copies or downloads the current rendered data and opens a fullscreen view.

<PrimitiveExample id="table" />

Provide a caption and meaningful column headers. Sorting, filtering and selection stay in your application. Fullscreen content is explicit: render the same table data inside `TableFullscreenContent` so both views stay in sync.
