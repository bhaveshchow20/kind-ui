Compose AvatarImage and AvatarFallback inside Avatar. The fallback remains available while an image loads or when it fails; use initials that remain recognizable at small sizes.

<PrimitiveExample id="avatar" />

Give the person an accessible name once. This example labels the root and uses an empty image `alt` to avoid announcing the same name twice.
