Use a Badge for short metadata that readers need to scan. Choose a tone that reinforces the label, and always express its meaning in text as well as color.

<PrimitiveExample id="badge" />

A badge renders a span by default. Put the action that changes it on a separate control, and add announcement semantics when an update needs to be heard.
