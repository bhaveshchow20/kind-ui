import { api } from "@/lib/primitives/popover";

Compose a trigger with `PopoverContent`, then add a title, description and close control. The content handles its portal and placement. Use `open` and `onOpenChange` when other parts of your interface need to coordinate visibility.

<PrimitiveExample id="popover" />

## API reference

`Content` combines the portal, positioner and styled popup. Use the individual parts when you need to control their markup or mounting. Element parts also accept refs, native attributes and event handlers.
