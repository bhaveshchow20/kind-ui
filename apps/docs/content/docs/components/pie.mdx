## Usage

`PieChart` requires `config`, an accessible name and explicit children. Add the parts you need; omitted parts stay absent. Set plot dimensions on the chart, shared actions on `interaction`, and outer HTML attributes on `frameProps`.

Set `categoryKey` for stable slice colors and `innerRadius` for a donut.

```tsx title="Composition sketch"
import { PieChart } from "@kind-ui/charts";

<PieChart config={config} defaultVisibleSeries={Object.keys(config)} interaction={{ kind: "category", eligibleKeys: data.map((row) => row.key) }} height={280} animate accessibilityLayer aria-label="Team allocation">
  <PieChart.Series data={data} dataKey="hours" categoryKey="key" nameKey="key" innerRadius={58} outerRadius={108}>
    <PieChart.Labels dataKey="share" position="inside" fill="white" stroke="none" style={{ fill: "white", fontWeight: 600 }} />
  </PieChart.Series>
  <PieChart.Tooltip itemKey={(entry) => String(entry.payload?.key ?? entry.name)} />
  <PieChart.Legend />
</PieChart>
```

Use the same stable category IDs for config, slices and tooltips. Set `animationDirection` to choose the entrance sweep.

Set category `interaction` on PieChart and `categoryKey` on its Series to share actions between slices and legend.

<ChartExample id="pie-interaction" />

<Callout title="Category identities">Supply unique string IDs and complete `eligibleKeys`, including hidden and zero-valued categories. Set category `interaction` on `PieChart`, give its Series a `categoryKey`, and retain complete data and Cells. Hiding suppresses a slice without reallocating its angle; `visibleSeries` alone does not bind slices.</Callout>

Focus highlights a slice; Enter/Space activates it and Escape resets. In explicit visibility mode, the legend keeps at least one category visible. Focus never changes visibility; explicit controls can clear focus. See [Chart interaction](/docs/chart-components/chart/) for controlled actions.

## Initial tooltip

Set `defaultPinnedCategory="service"` to open the first tooltip on Service. It follows that ID when rows reorder.

<Callout title="Initial tooltip">Use one category-keyed `PieChart.Series` with explicit data and one `PieChart.Tooltip` with `itemKey`. Compound parts can be wrapped in fragments or consumer components. Inspection or hiding the category dismisses the initial pin until remount; explicit tooltip state takes precedence.</Callout>

### Selective glow

Use `glowCategories={["design"]}` to decorate a specific category.

```tsx title="Selected category on a rounded donut"
import { PieChart } from "@kind-ui/charts";

<PieChart.Series
  data={data}
  dataKey="hours"
  categoryKey="key"
  nameKey="key"
  innerRadius={58}
  outerRadius={108}
  cornerRadius={8}
  paddingAngle={2}
  glowCategories={["design"]}
/>
```

Glow is decorative; keep category labels and readable fills.

## API reference

Configure the angular plot and its category-valued series.

### PieChart

Set the plot size on the chart and add its parts as children.

<div className="line-props-scroll" role="region" aria-label="PieChart props" tabIndex={0}>

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `config` | `SeriesConfig` | Required | Series or category labels, colors and formatting. |
| `interaction` | `ChartInteractionConfig` | Family focus | Shared legend and supported mark actions; eligibility remains explicit. |
| `frameProps` | HTML frame attributes | — | Styles, handlers, data attributes and ref for the outer HTML frame. |
| `animate` | `boolean \| PieAnimation` | `false` | Sector entrance and interaction motion; respects reduced motion. |
| `animationDirection` | `"clockwise" \| "anticlockwise"` | `"clockwise"` | Continuous entrance sweep; native geometry and row order stay unchanged. |
| `defaultPinnedCategory` | `string` | Off | Initial category tooltip; requires one category-keyed PieChart.Series and one Tooltip. Dismissal is permanent until remount. |
| `loading` | `boolean` | `false` | Explicit pending state with a chart-owned loading illustration and blocked inspection. |
| `loadingLabel` | `string` | `"Loading chart"` | Accessible pending status. |
| `accessibilityLayer` | `boolean` | `true` in Recharts | Enables native keyboard inspection; set explicitly here. |
| `aria-label` / `aria-labelledby` | `string` | — | Accessible chart name. |
| `children` | `ReactNode` | Required | Explicit PieChart.Series, labels and tooltip. |

</div>

`PieAnimation` accepts `revealDurationMs` (default `1000`), `revealEasing` and `hoverTransition`. See [Recharts PieChart](https://recharts.github.io/en-US/api/PieChart/).

### PieChart.Series

Value and category identity use separate fields.

<div className="line-props-scroll" role="region" aria-label="PieChart.Series props" tabIndex={0}>

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `data` | `Row[]` | — | Consumer-owned category rows. |
| `dataKey` | `string \| number \| ((row: Row) => unknown)` | `"value"` in Recharts | Numeric value field or accessor; set explicitly here. |
| `categoryKey` | `string \| ((row: Row) => string)` | Off | Resolves an own top-level field or accessor into chart `config`; requires explicit series data and string IDs. |
| `nameKey` | `string \| number \| ((row: Row) => unknown)` | `"name"` | Native category name; use config keys for semantic identity. |
| `innerRadius` | `number` or percentage | `0` | A positive radius produces a Donut. |
| `outerRadius` | `number` or percentage | `"80%"` | Sector size; percentages use Recharts' available radius. |
| `startAngle` / `endAngle` | `number` | `0` / `360` | Native angular geometry in degrees. |
| `paddingAngle` | `number` | `0` | Native gap in degrees; keep total padding below the angular sweep. |
| `cornerRadius` | `number \| string` | `0` | Native rounded sector corners; numeric units are recommended here. |
| `material` | `"clay" \| "glow"` | Omitted | Finish on default sectors; consumer rendering can take precedence. |
| `glowCategories` | `readonly string[]` | Off | Category IDs receiving glow instead of `material`; requires `categoryKey` and explicit data. Unknown IDs are ignored. |
| `emphasisKey` | `(payload: unknown) => string \| number \| undefined` | Native name | Optional semantic sector identity for paint emphasis; does not configure tooltip identity. |
| `stroke` | `string` | `"none"` | Native sector outline. |

</div>

Explicit series fill overrides config colors; datum/Cell fill wins. Custom rendering may bypass materials. See [Recharts Pie](https://recharts.github.io/en-US/api/Pie/).

## Shared components

Keep slice identities, legend actions and tooltip formatting aligned with these components.

| Component | Purpose |
| --- | --- |
| [Chart frame](/docs/chart-components/chart/) | Share colors, formatting and series visibility. |
| [SeriesConfig](/docs/chart-components/series-config/) | Name series and define their colors and value formats. |
| [Labels and cells](/docs/chart-components/labels/) | Annotate values and style individual marks. |
| [Legend](/docs/chart-components/legend/) | Identify series and focus by dimming other marks. |
| [Tooltip](/docs/chart-components/tooltip/) | Show values for the inspected mark. |

Place custom HTML controls or status text in the family’s `Content` part. Keep function/numeric data accessors paired with explicit `seriesKey` metadata.
