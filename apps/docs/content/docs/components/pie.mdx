## Usage

Supply your own data and accessible name. Both installation paths use this local component.

```tsx title="Dashboard.tsx"
import { PieChart, PieSeries } from "@/components/charts/pie-chart";

const data = [{ key: "sales", value: 120 }];
const config = { sales: { label: "Sales", color: "#733bff" } };

export function Dashboard() {
  return <PieChart config={config}  aria-label="Chart data"><PieSeries data={data} dataKey="value" nameKey="key" categoryKey="key" /></PieChart>;
}
```

The local file owns presentation defaults. Set `config` to use its frame; omit it when composing inside your own `Root`. Series and marks remain explicit children. Line, Heatmap and ActivityRings supply their own context.

See the [npm core installation](/docs/installation/#npm-core) for direct package imports. The API reference below describes the underlying core parts; the editable wrapper also accepts `config`, `rootProps`, `height`, `width` and optional `legend` where it supplies a frame.

## Controlled categories

This example explicitly opts into visibility. Hide a category without moving or resizing the remaining slices; the status reports visible hours.

<ChartExample id="pie-visibility" />

Use `interactionBinding="root"` to share category actions between slices and legend.

<ChartExample id="pie-interaction" />

<Callout title="Category identities">Supply unique string IDs and complete `eligibleKeys`, including hidden and zero-valued categories. Bind `PieSeries` to Root with `interactionBinding="root"` and retain the complete data and Cells. Hiding suppresses a slice without reallocating its angle; `visibleSeries` alone does not bind slices.</Callout>

Focus highlights a slice; Enter/Space activates it and Escape resets. In explicit visibility mode, the legend keeps at least one category visible. Focus never changes visibility; explicit controls can clear focus. See [Root interaction](/docs/chart-components/root/) for controlled actions.

## Initial tooltip

Set `defaultPinnedCategory="service"` to open the first tooltip on Service. It follows that ID when rows reorder.

<Callout title="Initial tooltip">Use one direct category-keyed `PieSeries` and one `Tooltip` with `itemKey`. Inspection or hiding the category dismisses the initial pin until remount; explicit tooltip state takes precedence.</Callout>

### Selective glow

Use `glowCategories={["design"]}` to decorate a specific category.

```tsx title="Selected category on a rounded donut"
<Chart.PieSeries
  data={data}
  dataKey="hours"
  categoryKey="key"
  nameKey="key"
  innerRadius={58}
  outerRadius={108}
  cornerRadius={8}
  paddingAngle={2}
  glowCategories={["design"]}
/>
```

Glow is decorative; keep category labels and readable fills.

## API reference

Configure the angular plot and its category-valued series.

### PieChart

Use inside a sized `ResponsiveContainer`.

<div className="line-props-scroll" role="region" aria-label="PieChart props" tabIndex={0}>

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `animate` | `boolean \| PieAnimation` | `false` | Sector entrance and interaction motion; respects reduced motion. |
| `animationDirection` | `"clockwise" \| "anticlockwise"` | `"clockwise"` | Continuous entrance sweep; native geometry and row order stay unchanged. |
| `defaultPinnedCategory` | `string` | Off | Initial category tooltip; requires one direct category-keyed PieSeries and one Tooltip. Dismissal is permanent until remount. |
| `loading` | `boolean` | `false` | Explicit pending state with a chart-owned loading illustration and blocked inspection. |
| `loadingLabel` | `string` | `"Loading chart"` | Accessible pending status. |
| `accessibilityLayer` | `boolean` | `true` in Recharts | Enables native keyboard inspection; set explicitly here. |
| `aria-label` / `aria-labelledby` | `string` | — | Accessible chart name. |
| `children` | `ReactNode` | — | Explicit PieSeries, labels and tooltip. |

</div>

`PieAnimation` accepts `revealDurationMs` (default `1000`), `revealEasing` and `hoverTransition`. See [Recharts PieChart](https://recharts.github.io/en-US/api/PieChart/).

### PieSeries

Value and category identity use separate fields.

<div className="line-props-scroll" role="region" aria-label="PieSeries props" tabIndex={0}>

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `data` | `Row[]` | — | Consumer-owned category rows. |
| `dataKey` | `string \| number \| ((row: Row) => unknown)` | `"value"` in Recharts | Numeric value field or accessor; set explicitly here. |
| `categoryKey` | `string \| ((row: Row) => string)` | Off | Resolves an own top-level field or accessor into `Root.config`; requires explicit series data and string IDs. |
| `interactionBinding` | `"root"` | Off | Shares category identities with category-kind Root interaction; filters original rows and Cells using Root visibility. |
| `nameKey` | `string \| number \| ((row: Row) => unknown)` | `"name"` | Native category name; use config keys for semantic identity. |
| `innerRadius` | `number` or percentage | `0` | A positive radius produces a Donut. |
| `outerRadius` | `number` or percentage | `"80%"` | Sector size; percentages use Recharts' available radius. |
| `startAngle` / `endAngle` | `number` | `0` / `360` | Native angular geometry in degrees. |
| `paddingAngle` | `number` | `0` | Native gap in degrees; keep total padding below the angular sweep. |
| `cornerRadius` | `number \| string` | `0` | Native rounded sector corners; numeric units are recommended here. |
| `material` | `"clay" \| "glow"` | Omitted | Finish on default sectors; consumer rendering can take precedence. |
| `glowCategories` | `readonly string[]` | Off | Category IDs receiving glow instead of `material`; requires `categoryKey` and explicit data. Unknown IDs are ignored. |
| `emphasisKey` | `(payload: unknown) => string \| number \| undefined` | Native name | Optional semantic sector identity for paint emphasis; does not configure tooltip identity. |
| `stroke` | `string` | `"none"` | Native sector outline. |

</div>

Explicit series fill overrides config colors; datum/Cell fill wins. Custom rendering may bypass materials. See [Recharts Pie](https://recharts.github.io/en-US/api/Pie/).
