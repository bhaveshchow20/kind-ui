## Usage

Each service occupies its share of the monthly bill. Color identifies its category. Compare August and September, inspect a tile, and read its category path in the tooltip.

```tsx title="Composition sketch"
import { TreemapChart } from "@kind-ui/charts";

<TreemapChart data={data} config={config} aria-label="Monthly cloud spend" animate>
  <TreemapChart.Tiles />
  <TreemapChart.Labels />
  <TreemapChart.Tooltip valueAnimation="shuffle" />
  <TreemapChart.Legend />
  <TreemapChart.Breadcrumbs rootLabel="All services" />
</TreemapChart>
```

Use `{ id, label, value }` for a leaf and `{ id, label, children }` for a group. IDs stay unique and stable across updates; group totals come from their descendants. Area values must be finite and nonnegative. Zero values remain in the data even when they have no drawable area.

The shared legend emphasizes categories without reallocating area. `animate` enables shared motion; `valueAnimation="shuffle"` rolls tooltip digits. Reduced motion is respected.

## API reference

<ApiTable name="TreemapRootReference" />

| Part | Purpose |
| --- | --- |
| `Tiles` | Leaf mosaic with native refs and handlers through `tileProps`. |
| `Groups` | Optional group controls when you explicitly set `groupHeaderHeight`; no header space is reserved by default. |
| `Labels` | Text directly in tiles; `minWidth`, `minHeight` and `padding` control fit. Custom content supplies units or a second line. |
| `Tooltip` | Shared floating readout, or typed custom `children`; `valueAnimation="shuffle"` animates default formatted values. |
| `Legend` | Shared category selection and visibility controls from `config`. |
| `ColorLegend` | Independent numeric or categorical color key, including unknown values. |
| `Breadcrumbs` | Open an ancestor; `rootLabel` names the complete dataset. |
| `Content`, `DataTable` | Optional application content and accessible tabular data outside the plot. |

Arrows and Home/End move between tiles and group headers. Enter/Space activates them; Escape dismisses inspection. `viewId` and `activeId` control navigation and inspection. `interaction` owns legend selection; `selectedId` remains available for legacy application actions. `rootShare`, `parentShare` and `viewShare` describe the supplied dataset, parent and current subtree respectively; zero denominators yield `null`.

`layout="stable"` retains rows across value and size updates. For your own record shape, use `accessors`; `encoding` colors by a separate metric. Formatters and filtering remain consumer-owned.
