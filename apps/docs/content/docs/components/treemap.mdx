## Usage

Each service occupies its share of one monthly bill. Color identifies its category. Inspect a tile for its service value and ancestor context.

```tsx title="Composition sketch"
import { TreemapChart } from "@kind-ui/charts";

<TreemapChart data={data} config={config} aria-label="Monthly cloud spend" animate>
  <TreemapChart.Tiles />
  <TreemapChart.Tooltip valueAnimation="shuffle" />
  <TreemapChart.Legend />
</TreemapChart>
```

`TreemapNode` is the input type. Use `{ id, label, value }` for a leaf and `{ id, label, children }` for a group. IDs stay unique and stable across updates; group totals come from their descendants. Area values must be finite and nonnegative. Zero values remain in the data even when they have no drawable area.

The shared legend emphasizes categories without reallocating area. `animate` enables shared motion; `valueAnimation="shuffle"` rolls tooltip digits. Reduced motion is respected.

## Loading State

Use **Show chart** to transition from the placeholder to data, or **Show loading** to return. The chart stays mounted; `animate` enables its entrance, and `loadingLabel` names the pending state.

## API reference

<ApiTable name="TreemapRootReference" />

### TreemapChart.Tiles

`Tiles` iterates the computed rectangles. Its default `Tile` paints one positioned button and binds shared emphasis, selection, cursor inspection and keyboard navigation. Customize an individual renderer without building another interaction layer:

```tsx
<TreemapChart.Tiles render={(props) => (
  <TreemapChart.Tile {...props} style={{ borderRadius: 8 }} />
)} />
```

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `labels` | `boolean` | `true` | Include fitted names and values inside tiles. |
| `tileProps` | `(node) => button props` | — | Native styles, handlers, attributes and ref for each tile. |
| `render` | `(props) => ReactNode` | `Tile` | Full renderer receiving the computed rectangle and native props. |
| `children` | `ReactNode` or `(node) => ReactNode` | Fitted name and value | Custom content replaces the default label. |

### TreemapChart.Tile

Each tile includes fitted text. Use `labels={false}` to omit it; native styles and `children` customize its presentation.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `node` | `TreemapRectangle<T>` | Required | Supplied geometry, identity, original datum and values from `Tiles.render`. |
| Native button props / ref | HTML button props | — | Consumer presentation and handlers; family inspection, emphasis and keyboard behavior remain bound. |
| `children` | `ReactNode` | Fitted name and value | Custom content replaces the default label. |

### TreemapChart.Tooltip

The family supplies ancestor context, the original leaf value and its share to the shared floating tooltip frame and row styling.

| Prop | Default | Purpose |
| --- | --- | --- |
| `valueAnimation` | None | `"shuffle"` uses the shared rolling number. |
| `children(item)` | Family readout | Custom content using the original datum and supplied values. |
| Native div props / ref | — | Consumer presentation and semantics. |

### TreemapChart.Legend and optional parts

`Legend` is the shared legend mounted outside the plot. Its [props and interaction modes](/docs/chart-components/legend/) apply unchanged.

| Part | Purpose |
| --- | --- |
| `Groups` | Optional group headers through `groupProps` / `headerProps`, with a positive `groupHeaderHeight`. |
| `ColorLegend` | Numeric or categorical independent encoding, including unknown values. |
| `Breadcrumbs` | Controlled hierarchy navigation; `rootLabel` names the dataset. |
| `Content` / `DataTable` | Application content or an accessible table outside the plot. |

## Shared components

Keep category colors, legend actions and tooltip presentation aligned with these components.

| Component | Purpose |
| --- | --- |
| [Chart frame](/docs/chart-components/chart/) | Share colors, visibility, interaction and loading state. |
| [SeriesConfig](/docs/chart-components/series-config/) | Name categories and define their colors. |
| [Legend](/docs/chart-components/legend/) | Identify categories and focus by dimming other tiles. |
| [Tooltip](/docs/chart-components/tooltip/) | Style the floating readout for the inspected tile. |

Arrows and Home/End move between tiles and group headers. Enter/Space activates them; Escape dismisses inspection. `viewId` and `activeId` control navigation and inspection. `interaction` owns legend selection; `selectedId` remains available for legacy application actions. `rootShare`, `parentShare` and `viewShare` describe the supplied dataset, parent and current subtree respectively; zero denominators yield `null`.

`layout="stable"` retains rows across value and size updates. For your own record shape, use `accessors`; `encoding` colors by a separate metric. Formatters and filtering remain consumer-owned.
