## Usage

Size shows capitalization; color shows signed return or activity. Change the color metric without changing area.

```tsx title="Composition sketch"
import { TreemapChart } from "@kind-ui/charts";

<TreemapChart
  data={data}
  accessors={accessors}
  encoding={encoding}
  config={{}}
  aria-label="Allocation and independent change metric"
  height={320}
>
  <TreemapChart.Groups />
  <TreemapChart.Tiles />
  <TreemapChart.Labels />
  <TreemapChart.Tooltip />
  <TreemapChart.ColorLegend />
  <TreemapChart.Breadcrumbs />
</TreemapChart>
```

## API reference

### TreemapChart

<ApiTable name="TreemapRootReference" />

Compose the owning chart with explicit parts. Supply a chart name, `config` and children; custom records also require `accessors`.

### Explicit parts

<div className="line-props-scroll" role="region" aria-label="Treemap compound parts" tabIndex={0}>

| Part | Main props | Behavior |
| --- | --- | --- |
| `Groups` | `groupProps`, `headerProps`, `children` | Nested outlines and navigation buttons. |
| `Tiles` | `tileProps`, `children` | Frontier buttons with consumer presentation, refs and handlers. |
| `Labels` | `minWidth`, `minHeight`, `padding`, `labelProps`, `children` | Clipped labels; defaults `40`, `22`, `4`. |
| `Tooltip` | `children` | Active `TreemapItem<T>` readout. |
| `ColorLegend` | HTML div props | Resolved color key and unknown swatch. |
| `Breadcrumbs` | `rootLabel`, HTML nav props | Ancestor navigation; default root label `"All"`. |
| `Content` | `children` | Consumer HTML outside the measured plot, with chart context. |
| `DataTable` | `caption`, `scope`, `rowProps`, `children` | Navigable data alternative; scope defaults to `"view"`, or use `"root"`. `rowProps` supplies attributes; `children` renders cells. |

</div>

Use a generic record type for custom content, such as `<TreemapChart.Tooltip<StorageRecord>>`. Keep tile/header content free of nested buttons.

### Data and shares

| Contract | Meaning |
| --- | --- |
| Standard leaf | `{ kind: "leaf", id, label, value }`. Area must be finite and nonnegative. |
| Standard group | `{ kind: "group", id, label, children }`. Area is derived from descendants; no independent `value`. |
| `TreemapAccessors<T>` | Adapt ID, label, children and leaf area. Original records are retained; area accessors run only for leaves. |
| Children | `undefined` identifies a leaf; `[]` identifies an empty group. |
| IDs and labels | IDs are globally unique, stable and nonempty. Nonempty labels may repeat. |
| Zero and missing | Zero-area leaves remain in semantic data. Missing area requires an adapter policy; missing color differs from zero. |
| Validation | Invalid children, cycles, shared records and overflowing totals throw location-specific errors. |
| Normalized node | Retains `datum`, `kind`, `parentId`, zero-based `depth`, ID `path` and derived `value`. |
| `rootShare` | Share of the supplied forest after application filtering. |
| `parentShare` | Share of the parent total, or forest total for roots. |
| `viewShare` | Share of the current subtree; `null` outside it. Zero denominators yield `null`. |

External denominators and accounting measures remain application metadata.

### State and interaction

| Contract | Behavior |
| --- | --- |
| `viewId`, `onViewChange` | Controlled subtree navigation. |
| `activeId`, `onActiveChange` | Transient inspection through pointer or keyboard focus. |
| `selectedId`, `onSelectionChange` | Persistent selection. |
| `default*Id` | Uncontrolled initial state; mutually exclusive with the corresponding controlled prop. Ownership stays fixed while mounted. |
| Removed IDs | Fall back to the nearest surviving ancestor, then forest root (`null`). |
| Callback items | Original records, `rectangle` (or `null`) and `viewShare`. |
| Keyboard | Enter/Space selects and opens groups; arrows and Home/End traverse controls; Escape dismisses inspection. |
| `layout="stable"` | Retains rows across weights/resizing; membership, regrouping and view changes invalidate the cache. |
| `layout="squarify"` | Recomputes rows. IDs preserve element identity, not fixed coordinates. |
| Small cells | Fit thresholds omit labels; records remain in the data alternative. |
| `animate` | Opt-in Motion with reduced-motion support. |
| `loading` | Pending state, independent of area/color metrics. Applications own cancellation, retries and filtering. |

### Color encoding

| Contract | Behavior |
| --- | --- |
| Modes | Categorical, sequential, zero-centered diverging, threshold and custom. Default: categorical root-group colors. |
| `domain` | Fixed endpoints or inferred from available metrics. |
| `domainScope` | `"root"` by default, or `"view"`. |
| Diverging domains | Inferred domains are symmetric; explicit domains must contain zero. |
| Equal endpoints/outliers | Equal endpoints use midpoint paint; outliers clamp paint without changing readouts. |
| Thresholds | Ascending finite boundaries with one more color than boundaries; boundaries enter the upper band. |
| `unknownColor`, `unknownLabel` | Missing/nonfinite metric paint and readout. |
| `groupValue`, `aggregate` | Explicit group metrics or numeric aggregation, mutually exclusive. No implicit averaging. |
| Formatters | Consumer-owned units, including percent versus percentage points. |

### Pure helpers

| Helper | Output |
| --- | --- |
| `normalizeTreemap(data, accessors?)` | Roots, preorder nodes, `byId` and total. Accessor-free input uses `TreemapDatum`. |
| `resolveTreemapColors(nodes, viewNodes, encoding)` | ID-keyed readouts and resolved legend, independent of area. |
