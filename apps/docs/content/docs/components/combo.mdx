## Usage

`ComboChart` requires `config`, an accessible name and explicit children. Add the parts you need; omitted parts stay absent. Set plot dimensions on the chart, shared actions on `interaction`, and outer HTML attributes on `frameProps`.

Combine `ComboChart.Bar`, `ComboChart.Area` and `ComboChart.Line` in one plot.

```tsx title="Composition sketch"
import { ComboChart } from "@kind-ui/charts";

<ComboChart config={config} defaultVisibleSeries={Object.keys(config)} height={280} data={data} animate accessibilityLayer aria-label="Monthly production in units">
  <ComboChart.Grid vertical={false} />
  <ComboChart.XAxis dataKey="period" />
  <ComboChart.YAxis domain={[0, 1200]} width={80} />
  <ComboChart.Area dataKey="capacity" type="stepAfter" fillOpacity={0.18} />
  <ComboChart.Bar dataKey="shipped" maxBarSize={32} />
  <ComboChart.Line dataKey="target" type="linear" dot={false} strokeDasharray="6 4" />
  <ComboChart.Tooltip />
  <ComboChart.Legend />
</ComboChart>
```

Set interpolation and paint on each series; format each axis for its measure.

## Percentage stacks

Use an expanded stack for proportions. Keep raw data; format the axis and tooltip as percentages.

```tsx
import { ComboChart, type SeriesConfig, createPercentStack } from "@kind-ui/charts";

const data = [{ month: "Jan", online: 60, store: 40 }];
const config = {
  online: { label: "Online", color: "#733bff" },
  store: { label: "Store", color: "#0f766e" },
} satisfies SeriesConfig;
const percent = createPercentStack({
  values: (entry) => [entry.payload.online, entry.payload.store],
});

export function PercentageChart() {
  return <ComboChart config={config} data={data} stackOffset="expand" aria-label="Sales channel share">
    <ComboChart.XAxis dataKey="month" />
    <ComboChart.YAxis domain={[0, 1]} tickFormatter={percent.tickFormatter} />
    <ComboChart.Bar dataKey="online" stackId="share" />
    <ComboChart.Bar dataKey="store" stackId="share" />
    <ComboChart.Tooltip normalizedValue={percent.normalizedValue} />
  </ComboChart>;
}
```

<Callout title="Note">If series can be hidden, make the `values` callback return only the visible members of the inspected stack. Already fractional values use `formatPercent` directly.</Callout>

## API reference

Configure the shared plot, then set options on each series.

### ComboChart

<div className="line-props-scroll" role="region" aria-label="ComboChart props" tabIndex={0}>

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `config` | `SeriesConfig` | Required | Series or category labels, colors and formatting. |
| `interaction` | `ChartInteractionConfig` | Family focus | Shared legend and supported mark actions; eligibility remains explicit. |
| `frameProps` | HTML frame attributes | — | Styles, handlers, data attributes and ref for the outer HTML frame. |
| `data` | `Row[]` | — | Shared category observations; Kind does not aggregate or transform them. |
| `animate` | `boolean \| ComboAnimation` | `false` | Chart-owned entrance and inspection motion, respecting reduced motion. |
| `layout` | `"horizontal" \| "vertical"` | `"horizontal"` | Native chart orientation; supply matching category and numeric axes. |
| `stackOffset` | `"none" \| "expand" \| "wiggle" \| "silhouette" \| "sign" \| "positive"` | `"none"` | Native stack calculation; formatting remains consumer-owned. |
| `barCategoryGap` / `barGap` | `number \| string` | `"10%"` / `4` | Category and grouped-bar spacing in native geometry. |
| `accessibilityLayer` | `boolean` | `true` in Recharts | Keyboard category inspection; enabled explicitly in these components. |
| `aria-label` / `aria-labelledby` | `string` | — | Consumer-supplied accessible plot name. |
| `children` | `ReactNode` | Required | Explicit axes, grid, series and tooltip. |

</div>

See [Recharts ComposedChart](https://recharts.github.io/en-US/api/ComposedChart/).

### ComboAnimation

Pass to `ComboChart.animate` to set timing by family.

<div className="line-props-scroll" role="region" aria-label="ComboAnimation options" tabIndex={0}>

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `revealDurationMs` | `number` | `1000` | Shared entrance duration in milliseconds. |
| `revealEasing` | `Transition["ease"]` | `[0.25, 0.1, 0.25, 1]` | Motion entrance easing. |
| `lineReveal` / `areaReveal` / `barReveal` | `false \| { revealDurationMs?: number; revealEasing?: Transition["ease"] }` | Shared options | Override one family's duration or easing; `false` skips its entrance. |
| `hoverTransition` | `Transition` | Spring: `210` stiffness, `28` damping, `0.8` mass | Shared inspection motion; family entrance options do not override it. |

</div>

### ComboChart.Line

<div className="line-props-scroll" role="region" aria-label="ComboChart.Line props" tabIndex={0}>

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `dataKey` | `string \| number \| ((row: Row) => unknown)` | Required | Native line values. |

## Shared components

Share series metadata and inspection across the bars, lines and areas.

| Component | Purpose |
| --- | --- |
| [Chart frame](/docs/chart-components/chart/) | Share colors, formatting and series visibility. |
| [SeriesConfig](/docs/chart-components/series-config/) | Name series and define their colors and value formats. |
| [Axes and grid](/docs/chart-components/axes-grid/) | Label scales and add comparison guides. |
| [Legend](/docs/chart-components/legend/) | Identify series and focus by dimming other marks. |
| [Tooltip](/docs/chart-components/tooltip/) | Show values for the inspected mark. |

Place custom HTML controls or status text in the family’s `Content` part. Keep function/numeric data accessors paired with explicit `seriesKey` metadata.
