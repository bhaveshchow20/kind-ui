Bars show shipped units, the shaded area shows available capacity, and the dashed line marks the production target. All three use the same unit and scale.

## Usage

`Root` supplies series metadata and colors. `ComboChart` shares native category geometry and tooltip inspection across explicitly composed series; `ResponsiveContainer` provides measured dimensions. The first Code tab contains a complete named component with its data and imports.

```tsx title="Composition"
<Chart.Root config={config}>
  <Chart.Legend />
  <Chart.ResponsiveContainer width="100%" height={280}>
    <Chart.ComboChart data={data} animate accessibilityLayer aria-label="Monthly production in units">
      <Chart.CartesianGrid vertical={false} />
      <Chart.XAxis dataKey="period" />
      <Chart.YAxis domain={[0, 1200]} />
      <Chart.AreaSeries dataKey="capacity" type="stepAfter" fillOpacity={0.18} />
      <Chart.BarSeries dataKey="shipped" maxBarSize={32} />
      <Chart.LineSeries dataKey="target" type="linear" dot={false} strokeDasharray="6 4" />
      <Chart.Tooltip />
    </Chart.ComboChart>
  </Chart.ResponsiveContainer>
</Chart.Root>
```

Recharts owns scales, axes and stacking; Kind supplies registered metadata, controlled visibility and chart motion. Choose each series' interpolation, paint and mark props directly. The step area represents capacity changes; the dashed target stays distinct from actual shipments. `ComboChart` accepts native composed-chart props rather than Line's configured `series` or `xDataKey` shortcuts.

## Stacks and two axes

Retail and wholesale bars share `stackId="revenue"` and `yAxisId="revenue"`. Their heights add in USD. Margin belongs to `yAxisId="margin"` on the right, with a percentage domain and percentage ticks. Legend labels and tooltip formatters keep the units visible. Compare revenue totals and margin trends using their own axes; their vertical positions do not express equal values.

<ChartExample id="combo-stacked" />

The legend controls consumer-owned visibility through `Root`. Hiding a revenue series recalculates its native stack; hiding margin leaves the revenue stack intact. Stacks remain native to each series family and matching axes: a shared `stackId` does not turn a line into a stacked bar or merge bar and area geometry. `stackOffset="expand"` changes stack calculation, so normalized axis labels and tooltip percentages need explicit consumer formatting.

## Family motion

Choose independent timing, a shared entrance, or line-only motion. Independent timing shows capacity immediately, reveals bars over 1000 ms and draws the target over 600 ms. Changing the selection remounts this example to replay its entrance; that replay is owned by the example.

<ChartExample id="combo-motion" />

Line and Area reveal across the plot; Bar reveals outward from its own numeric-axis zero baseline, clamped to the domain. Family options affect entrances only. Hover transitions remain shared. Pointer, focus or keyboard input finishes active entrances; data, visibility, size or composition changes also cancel them. Reduced motion shows final geometry and disables Kind motion, including when the preference changes after mounting.

## API reference

These focused props describe the maintained composition. Native Recharts props remain available through the public types; upstream references cover additional geometry options.

### Root

<div className="line-props-scroll" role="region" aria-label="Root props" tabIndex={0}>

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `config` | `SeriesConfig` | Required | Labels, colors and optional `formatValue` for all composed families. |
| `visibleSeries` | `readonly string[]` | All series | Consumer-owned selection across the shared Root. |
| `onVisibleSeriesChange` | `(keys: string[]) => void` | — | Enables legend toggles with controlled `visibleSeries`. |
| `emphasis` | `"auto" \| "none"` | `"auto"` | Shared emphasis policy; Combo inspection does not automatically dim marks. |

</div>

### ComboChart

<div className="line-props-scroll" role="region" aria-label="ComboChart props" tabIndex={0}>

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `data` | `Row[]` | — | Shared category observations; Kind does not aggregate or transform them. |
| `animate` | `boolean \| ComboAnimation` | `false` | Chart-owned entrance and inspection motion, respecting reduced motion. |
| `layout` | `"horizontal" \| "vertical"` | `"horizontal"` | Native chart orientation; supply matching category and numeric axes. |
| `stackOffset` | `"none" \| "expand" \| "wiggle" \| "silhouette" \| "sign" \| "positive"` | `"none"` | Native stack calculation; formatting remains consumer-owned. |
| `barCategoryGap` / `barGap` | `number \| string` | `"10%"` / `4` | Category and grouped-bar spacing in native geometry. |
| `accessibilityLayer` | `boolean` | `true` in Recharts | Keyboard category inspection; enabled explicitly in these components. |
| `aria-label` / `aria-labelledby` | `string` | — | Consumer-supplied accessible plot name. |
| `children` | `ReactNode` | — | Explicit axes, grid, series and tooltip. |

</div>

See [Recharts ComposedChart](https://recharts.github.io/en-US/api/ComposedChart/).

### ComboAnimation

Pass this object to `ComboChart.animate`.

<div className="line-props-scroll" role="region" aria-label="ComboAnimation options" tabIndex={0}>

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `revealDurationMs` | `number` | `1000` | Shared entrance duration in milliseconds. |
| `revealEasing` | `Transition["ease"]` | `[0.25, 0.1, 0.25, 1]` | Motion entrance easing. |
| `lineReveal` / `areaReveal` / `barReveal` | `false \| { revealDurationMs?: number; revealEasing?: Transition["ease"] }` | Shared options | Override one family's duration or easing; `false` skips its entrance. |
| `hoverTransition` | `Transition` | Spring: `210` stiffness, `28` damping, `0.8` mass | Shared inspection motion; family entrance options do not override it. |

</div>

### BarSeries

<div className="line-props-scroll" role="region" aria-label="BarSeries props" tabIndex={0}>

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `dataKey` | `string \| number \| ((row: Row) => unknown)` | Required | Native value field or accessor. |
