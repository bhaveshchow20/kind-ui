## Usage

Open **Code** above for the complete example, including data and imports.

Pass `data` and `config` to `LineChart`. Customize its defaults or compose plot parts as children.

Use `legend={{}}` to show the legend.

```tsx title="Imports"
import * as Chart from "@kind-ui/charts";
import "@kind-ui/charts/styles.css";
```

```tsx title="Composition sketch"
<Chart.LineChart data={data} config={config} legend={{}} aria-label="Monthly visitors">
  <Chart.CartesianGrid vertical={false} />
  <Chart.XAxis dataKey="period" />
  <Chart.YAxis />
  <Chart.LineSeries dataKey="visitors" type="monotone" />
  <Chart.Tooltip />
</Chart.LineChart>
```

Omit explicit children and pass `xDataKey="period"` to use the default grid, axes, series and tooltip.

## Point markers, dashed lines and reveal direction

Choose a presentation to see the effect and copy its complete example.

<ChartExample id="line-presentation" />

- **Markers:** `pointStyle="colored-border"` adds outlined points.
- **Animated dashes:** `strokeDasharray="6 4"` with `dashAnimation={{ durationMs: 1000 }}` moves the pattern.
- **Reveal direction:** `animate={{ revealDirection: "center-out" }}` draws from the center.

<Callout title="Note">Motion respects reduced motion. Explicit `dot`, `activeDot` and custom marker renderers override the built-in point styles.</Callout>

For custom point styling, pass `dot={<Chart.PointMarker variant="colored-border" />}` to `LineSeries`; see the [PointMarker reference](https://github.com/bhaveshchow20/kind-ui/blob/main/packages/charts/README.md#point-marker-styles).

## Decorative backgrounds

Select **Background** in the [Line presentation example](/docs/components/line/#point-markers-dashed-lines-and-reveal-direction), or add a preset to your chart:

```tsx
<Chart.LineChart data={data} config={config} xDataKey="period"
  backgroundPattern={{ pattern: "crossings", opacity: 0.15 }}
  aria-label="Monthly visitors" />
```

Presets: `"pinpoints"`, `"crossings"`, `"waves"`. Decoration stays behind the data.

## API reference

Passing `config` enables the defaults below. Omit `config` for the existing `Root` + `LineChart` composition.

### LineChart

Each config key generates a series unless you provide `series` or explicit children.

<div className="line-props-scroll" role="region" aria-label="LineChart props" tabIndex={0}>

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `data` | `readonly Row[]` | Required | Observations to plot. |
| `config` | `SeriesConfig` | Required in configured mode | Series labels, colors and optional value formatters. |
| `xDataKey` | `DataKey<Row>` | Required with generated parts | Field or accessor for x-axis labels. Omit with explicit children. |
| `aria-label` / `aria-labelledby` | `string` | One required | Accessible chart name. Keyboard inspection instructions are provided. |
| `height` / `width` | Native chart dimensions | `280px` / `100%` | Responsive plot dimensions; `style` and `className` can also override sizing. |
| `curve` | Recharts curve type | `"monotone"` | Curve for generated series; use `"linear"` or `"stepAfter"` here. |
| `material` | `"clay" \| "glow"` | Omitted | Finish for generated series, preserving native geometry. |
| `series` | `ConfiguredLineSeries<Row>[]` | Config keys | Per-series props; each entry needs `dataKey` and a unique `seriesKey` in config. |
| `xAxis` / `yAxis` / `grid` | Native props or `false` | Styled axes and horizontal grid | Override generated parts or hide them. |
| `tooltip` / `legend` | Kind props or `false` | Enabled with generated parts | Override or hide the tooltip and legend. Explicit children need `legend={{}}` to add a legend. |
| `animate` | `boolean` or `LineAnimation` | `true` configured; `false` legacy | Entrance and emphasis motion; respects reduced motion. |
| `defaultVisibleSeries` | `readonly string[]` | All series | Initial uncontrolled selection. Legend toggles update it automatically. |
| `visibleSeries` / `onVisibleSeriesChange` | `readonly string[]` / callback | Uncontrolled | Provide both for controlled toggles. Without a callback, controlled visibility is read-only. |
| `children` | `ReactNode` | Generated parts | Explicit children replace the plot parts, including `null` or an empty fragment. |

</div>

<Callout title="Composition">A configured chart already supplies `Root`. With explicit children, set series and plot options on those children.</Callout>

See [Recharts LineChart](https://recharts.github.io/en-US/api/LineChart/) for native plot props.

### LineSeries

Compose `LineSeries` as children, or pass its props through configured `series`. String `dataKey` values identify config entries; accessor and numeric keys use `seriesKey`.

<div className="line-props-scroll" role="region" aria-label="LineSeries props" tabIndex={0}>

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `dataKey` | `DataKey<Row>` | Required | Value field or accessor. |
| `seriesKey` | `string` | String `dataKey` | Config and visibility identity; required in a `series` array. |
| `type` | Recharts curve type | `"linear"` explicit; `"monotone"` generated | Curve for this line. |
| `material` | `"clay" \| "glow"` | Omitted | Line finish; custom `shape` or `filter` takes precedence. |
| `dot` | Native dot props or renderer | `true` explicit; radius `2.5` generated | Point markers; use `false` to hide them. |
| `strokeWidth` / `strokeDasharray` | `number` / `string` | Width `1` explicit / `2` generated; no dashes | Stroke weight and dash pattern. |

</div>

Missing values remain gaps unless `connectNulls` is enabled. See [Recharts Line](https://recharts.github.io/en-US/api/Line/) for native marks and [material support](/docs/guides/materials/) for finishes.
