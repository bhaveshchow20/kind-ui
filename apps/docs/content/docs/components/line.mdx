## Usage

Add one `LineChart.Series` per measure. Use `type="monotone"` for smooth curves and include `LineChart.Legend` to show the legend.

```tsx title="Composition sketch"
import { LineChart } from "@kind-ui/charts";

<LineChart data={data} config={config} aria-label="Monthly visitors">
  <LineChart.Grid vertical={false} />
  <LineChart.XAxis dataKey="period" />
  <LineChart.YAxis />
  <LineChart.Series dataKey="visitors" type="monotone" />
  <LineChart.Tooltip />
  <LineChart.Legend />
</LineChart>
```

## Point markers, dashed lines and reveal direction

Choose a presentation to see the effect and copy its complete example.

<ChartExample id="line-presentation" />

- **Markers:** `pointStyle="colored-border"` adds outlined points.
- **Animated dashes:** `strokeDasharray="6 4"` with `dashAnimation={{ durationMs: 1000 }}` moves the pattern.
- **Reveal direction:** `animate={{ revealDirection: "center-out" }}` draws from the center.

<Callout title="Note">Motion respects reduced motion. Explicit `dot`, `activeDot` and custom marker renderers override the built-in point styles.</Callout>

For custom point styling, pass `dot={<PointMarker variant="colored-border" />}` to `LineChart.Series`; see the [PointMarker reference](https://github.com/bhaveshchow20/kind-ui/blob/main/packages/charts/README.md#point-marker-styles).

## Decorative backgrounds

Select **Background** in the [Line presentation example](/docs/components/line/#point-markers-dashed-lines-and-reveal-direction), or add a preset to your chart:

```tsx
import { LineChart } from "@kind-ui/charts";

<LineChart data={data} config={config} aria-label="Monthly visitors">
  <LineChart.Background pattern="crossings" opacity={0.15} />
  <LineChart.XAxis dataKey="period" />
  <LineChart.Series dataKey="visitors" />
</LineChart>
```

Presets: `"pinpoints"`, `"crossings"`, `"waves"`. Decoration stays behind the data.

## API reference

Pass `config`, an accessible name and explicit children.

### LineChart

Add one `LineChart.Series` for each measure you want to plot.

<div className="line-props-scroll" role="region" aria-label="LineChart props" tabIndex={0}>

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `interaction` | `ChartInteractionConfig` | Family focus | Shared legend and supported mark actions; eligibility remains explicit. |
| `frameProps` | HTML frame attributes | — | Styles, handlers, data attributes and ref for the outer HTML frame. |
| `data` | `readonly Row[]` | — | Chart rows; per-series native data remains available. |
| `config` | `SeriesConfig` | Required | Series labels, colors and optional value formatters. |
| `aria-label` / `aria-labelledby` | `string` | One required | Accessible chart name. Keyboard inspection instructions are provided. |
| `height` / `width` | Native chart dimensions | `280px` / `100%` | Responsive plot dimensions; `style` and `className` can also override sizing. |
| `animate` | `boolean` or `LineAnimation` | `true` | Entrance and emphasis motion; respects reduced motion. |
| `defaultVisibleSeries` | `readonly string[]` | All series | Initial uncontrolled visibility. Explicit visibility interaction lets legend actions update it. |
| `visibleSeries` / `onVisibleSeriesChange` | `readonly string[]` / callback | Uncontrolled | Consumer-controlled visual visibility; explicit visibility mode enables legend hide/show. Without a callback, visibility is read-only. |
| `children` | `ReactNode` | Required | Explicit plot parts; `null` or an empty fragment intentionally omits them. |

</div>

<Callout title="Composition">Set axes, series, tooltip and legend options on their explicit parts.</Callout>

See [Recharts LineChart](https://recharts.github.io/en-US/api/LineChart/) for native plot props.

### LineChart.Series

Compose `LineChart.Series` as children. String `dataKey` values identify config entries; accessor and numeric keys use `seriesKey`.

<div className="line-props-scroll" role="region" aria-label="LineChart.Series props" tabIndex={0}>

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `dataKey` | `DataKey<Row>` | Required | Value field or accessor. |
| `seriesKey` | `string` | String `dataKey` | Config and visibility identity for accessor and numeric data keys. |
| `type` | Recharts curve type | `"linear"` | Curve for this line. |
| `dot` | Native dot props or renderer | `true` | Point markers; use `false` to hide them. |
| `strokeWidth` / `strokeDasharray` | `number` / `string` | Width `1`; no dashes | Stroke weight and dash pattern. |

</div>

Missing values remain gaps unless `connectNulls` is enabled. See [Recharts Line](https://recharts.github.io/en-US/api/Line/) for native marks and [material support](/docs/guides/materials/) for finishes.
