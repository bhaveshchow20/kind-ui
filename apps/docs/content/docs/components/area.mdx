## Usage

`AreaChart` owns its Root and responsive plot when given `config`. Include each part explicitly; metadata does not create marks, axes, tooltips or legends. Omitted parts stay absent. `height` controls the plot; `rootProps` controls the outer frame and shared interaction.

Add one `AreaSeries` per measure. Use `stackId` to stack related series.

```tsx title="Composition sketch"
<Chart.AreaChart config={config} defaultVisibleSeries={Object.keys(config)} height={280} data={data} animate accessibilityLayer aria-label="Monthly visitors">
  <Chart.AreaChart.Grid vertical={false} />
  <Chart.AreaChart.XAxis dataKey="period" />
  <Chart.AreaChart.YAxis />
  <Chart.AreaChart.Series dataKey="visitors" type="monotone" fillOpacity={0.22} />
  <Chart.AreaChart.Tooltip />
  <Chart.AreaChart.Legend />
</Chart.AreaChart>
```

The compound legend mounts outside the plot while remaining a child in your composition. Legend focuses and dims by default; explicit `interaction.mode="visibility"` enables hide/show.

## API reference

Use these props to configure the area plot and its series.

### AreaChart

With `config`, this family owns its Root and responsive plot. Add its parts explicitly.

<div className="line-props-scroll" role="region" aria-label="AreaChart props" tabIndex={0}>

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `data` | `Row[]` | — | Observations for explicit series and axes. |
| `animate` | `boolean \| AreaAnimation` | `false` | Chart-owned entrance and inspection motion; respects reduced motion. |
| `accessibilityLayer` | `boolean` | `true` in Recharts | Enables arrow-key inspection. Set explicitly in these components. |
| `aria-label` / `aria-labelledby` | `string` | — | Accessible plot name. |
| `margin` | `{ top?: number; right?: number; bottom?: number; left?: number }` | `5` each side | Space around plot parts. |
| `stackOffset` | `"none" \| "expand" \| "wiggle" \| "silhouette" \| "sign" \| "positive"` | `"none"` | Native stack calculation. `"expand"` normalizes stacks; labels and tooltip formatting stay consumer-owned. |
| `children` | `ReactNode` | — | Explicit axes, areas, grid and tooltip. |

</div>

See [Recharts AreaChart](https://recharts.github.io/en-US/api/AreaChart/).

### AreaSeries

String `dataKey` values identify config entries. Use `seriesKey` for numeric keys or accessors when controlling visibility.

<div className="line-props-scroll" role="region" aria-label="AreaSeries props" tabIndex={0}>

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `dataKey` | `string \| number \| ((row: Row) => unknown)` | Required | Value field or accessor. |
| `seriesKey` | `string` | String `dataKey` | Metadata and visibility identity. |
| `type` | `"basis" \| "basisClosed" \| "basisOpen" \| "bumpX" \| "bumpY" \| "bump" \| "linear" \| "linearClosed" \| "natural" \| "monotoneX" \| "monotoneY" \| "monotone" \| "step" \| "stepBefore" \| "stepAfter"` or custom curve function | `"linear"` | Native curve interpolation. |
| `stackId` | `string \| number` | — | Shared identity for stacked series. |
| `material` | `"clay" \| "glow"` | Omitted | Area finish; explicit `shape` or `filter` takes precedence. |
| `stroke` / `fill` | `string` | Config color | Override outline or fill separately. |
| `fillOpacity` | `number` | `0.6` in Recharts | Fill transparency; shown components set it explicitly. |
| `connectNulls` | `boolean` | `false` | Connect missing values instead of leaving gaps. |
| `hide` | `boolean` | `false` | Hide a series; Root selection also applies. |

</div>

`AreaChart` controls animation. See [Recharts Area](https://recharts.github.io/en-US/api/Area/) and [material support](/docs/guides/materials/).

## Shared components

Customize series colors, stack visibility and plot labels with these components.

| Component | Purpose |
| --- | --- |
| [Root](/docs/chart-components/root/) | Share colors, formatting and series visibility. |
| [SeriesConfig](/docs/chart-components/series-config/) | Name series and define their colors and value formats. |
| [Axes and grid](/docs/chart-components/axes-grid/) | Label scales and add comparison guides. |
| [Legend](/docs/chart-components/legend/) | Identify series and focus by dimming other marks. |
| [Tooltip](/docs/chart-components/tooltip/) | Show values for the inspected mark. |
| [ResponsiveContainer](/docs/chart-components/responsive-container/) | Size composed charts to their container. |

The named parts and explicit `Root`/`ResponsiveContainer` composition remain available for advanced layouts and server-rendered legends. Compound HTML parts mount in the browser. Keep function/numeric data accessors paired with explicit `seriesKey` metadata.
