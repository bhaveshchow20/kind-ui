## Usage

`Root` supplies metadata; `ResponsiveContainer` sizes the plot. Compose axes, `AreaSeries` and `Tooltip` inside `AreaChart`, which owns motion and inspection.

```tsx title="Composition"
<Chart.Root config={config}>
  <Chart.Legend />
  <Chart.ResponsiveContainer width="100%" height={280}>
    <Chart.AreaChart data={data} animate accessibilityLayer aria-label="Monthly visitors">
      <Chart.CartesianGrid vertical={false} />
      <Chart.XAxis dataKey="period" />
      <Chart.YAxis />
      <Chart.AreaSeries dataKey="visitors" type="monotone" fillOpacity={0.22} />
      <Chart.Tooltip />
    </Chart.AreaChart>
  </Chart.ResponsiveContainer>
</Chart.Root>
```

Area uses explicit composition, without Line’s configured shortcuts. Place `Legend` outside the plot; pair Root visibility with its callback for toggles.

## API reference

Focused props for the composition above; upstream links cover additional native options.

### Root

Shares metadata and visibility; data and sizing belong to the plot.

<div className="line-props-scroll" role="region" aria-label="Root props" tabIndex={0}>

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `config` | `SeriesConfig` | Required | Series labels, colors and optional value formatters. |
| `visibleSeries` | `readonly string[]` | All series | Consumer-owned series selection. |
| `onVisibleSeriesChange` | `(keys: string[]) => void` | — | Enables legend buttons; requires `visibleSeries`. |
| `emphasis` | `"auto" \| "none"` | `"auto"` | Enables supported paint emphasis; tooltip inspection does not automatically emphasize an area. |

</div>

### AreaChart

Compose inside `Root` and a sized `ResponsiveContainer`.

<div className="line-props-scroll" role="region" aria-label="AreaChart props" tabIndex={0}>

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `data` | `Row[]` | — | Observations for explicit series and axes. |
| `animate` | `boolean \| AreaAnimation` | `false` | Chart-owned entrance and inspection motion; respects reduced motion. |
| `accessibilityLayer` | `boolean` | `true` in Recharts | Enables arrow-key inspection. Set explicitly in these components. |
| `aria-label` / `aria-labelledby` | `string` | — | Accessible plot name. |
| `margin` | `{ top?: number; right?: number; bottom?: number; left?: number }` | `5` each side | Space around plot parts. |
| `stackOffset` | `"none" \| "expand" \| "wiggle" \| "silhouette" \| "sign" \| "positive"` | `"none"` | Native stack calculation. `"expand"` normalizes stacks; labels and tooltip formatting stay consumer-owned. |
| `children` | `ReactNode` | — | Explicit axes, areas, grid and tooltip. |

</div>

See [Recharts AreaChart](https://recharts.github.io/en-US/api/AreaChart/).

### AreaSeries

String `dataKey` values identify config entries. Use `seriesKey` for numeric keys or accessors when controlling visibility.

<div className="line-props-scroll" role="region" aria-label="AreaSeries props" tabIndex={0}>

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `dataKey` | `string \| number \| ((row: Row) => unknown)` | Required | Value field or accessor. |
| `seriesKey` | `string` | String `dataKey` | Metadata and visibility identity. |
| `type` | `"basis" \| "basisClosed" \| "basisOpen" \| "bumpX" \| "bumpY" \| "bump" \| "linear" \| "linearClosed" \| "natural" \| "monotoneX" \| "monotoneY" \| "monotone" \| "step" \| "stepBefore" \| "stepAfter"` or custom curve function | `"linear"` | Native curve interpolation. |
| `stackId` | `string \| number` | — | Shared identity for stacked series. |
| `material` | `"plain" \| "paper" \| "clay" \| "glow"` | `"plain"` | Area finish; explicit `shape` or `filter` takes precedence. |
| `stroke` / `fill` | `string` | Config color | Override outline or fill separately. |
| `fillOpacity` | `number` | `0.6` in Recharts | Fill transparency; shown components set it explicitly. |
| `connectNulls` | `boolean` | `false` | Connect missing values instead of leaving gaps. |
| `hide` | `boolean` | `false` | Hide a series; Root selection also applies. |

</div>

Numbers and two-value ranges retain native geometry. `AreaChart` owns motion; per-series animation is disabled. See [Recharts Area](https://recharts.github.io/en-US/api/Area/) and [material support](/docs/guides/materials/).

### Legend

Place outside `ResponsiveContainer`. Root visibility and its callback enable keyboard-operable toggles; otherwise items are labels.

<div className="line-props-scroll" role="region" aria-label="Legend props" tabIndex={0}>

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `hideIcon` | `boolean` | `false` | Use swatches instead of configured icons. |
| `emphasis` | `"none" \| "series"` | `"none"` | Requests series emphasis on hover or focus; supported paint behavior is family-specific. |

</div>

### Tooltip

Compose inside `AreaChart`. Hidden series are excluded. ArrowLeft/ArrowRight inspect observations; Escape dismisses inspection.

<div className="line-props-scroll" role="region" aria-label="Tooltip props" tabIndex={0}>

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `cursor` | Native cursor props or renderer | `false` | Optional inspection guide. |
| `maxWidth` | `number` | `180` | Tooltip width bound in pixels. |

</div>

See [Recharts Tooltip](https://recharts.github.io/en-US/api/Tooltip/).
