## How it works

The native axes use daily completed tasks and an explicit zero baseline. Thursday is missing, and the area preserves that gap with `connectNulls={false}`. The table retains every observation.

An area is not automatically normalized or stacked. Supply native `stackId`, geometry and appropriate domains when your data calls for them. This example demonstrates a single series with Plain or Paper.
