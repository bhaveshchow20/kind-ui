## How it works

The native axes use daily completed tasks and an explicit zero baseline. All seven daily observations are present; the native monotone curve connects them. The table retains every observation.

An area is not automatically normalized or stacked. Supply native `stackId`, geometry and appropriate domains when your data calls for them. This composition uses a single Plain series; Paper is also supported by the maintained mark.
