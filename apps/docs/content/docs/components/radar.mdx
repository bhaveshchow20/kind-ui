## How it works

Actual and target use native polar axes and a fixed 0–100 domain. This shared score scale allows comparison across dimensions; it does not imply additive totals. Legend visibility is controlled by example settings and the table keeps all five dimensions.

Plain and Paper decorate the maintained polygon. Native keyboard inspection is separate from category paint emphasis, which is not implemented for Radar.
