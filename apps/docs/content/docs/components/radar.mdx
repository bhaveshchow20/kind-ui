## Usage

`RadarChart` requires `config`, an accessible name and explicit children. Add the parts you need; omitted parts stay absent. Set plot dimensions on the chart, shared actions on `interaction`, and outer HTML attributes on `frameProps`.

Compare measures on a shared radial scale with one `RadarChart.Series` per profile.

```tsx title="Composition sketch"
import { RadarChart } from "@kind-ui/charts";

<RadarChart config={config} defaultVisibleSeries={Object.keys(config)} height={280} data={data} animate outerRadius="68%" aria-label="Product research scores out of 100">
  <RadarChart.Grid radialLines={false} />
  <RadarChart.AngleAxis dataKey="period" />
  <RadarChart.RadiusAxis domain={[0, 100]} ticks={[25, 50, 75, 100]} />
  <RadarChart.Series dataKey="studio" fillOpacity={0.18} />
  <RadarChart.Series dataKey="field" fillOpacity={0.18} />
  <RadarChart.Tooltip />
  <RadarChart.Legend />
</RadarChart>
```

Use comparable units and a fixed domain across spokes. These research scores share a 0–100 scale.

## Center-out motion

Set `animate` for a center-out entrance that respects reduced motion.

## Series selection

Click a polygon or press Enter/Space to select it. Repeat or press Escape to clear.

<ChartExample id="radar-selection" />

Set `RadarChart.interaction` to `{ kind: "series", mode: "focus", eligibleKeys }`. Pair `selected` with `onSelectionChange` for controlled focus.

Selection highlights a profile without hiding other values.

<Callout title="Keyboard access">Series controls support selection, but not arrow-key navigation between spokes. Use a meaningful chart name and clear profile labels.</Callout>

## API reference

Configure the shared scale, profile selection and series styling.

### RadarChart

Pass `config` and an accessible name, then add the axes and series as children.

<div className="line-props-scroll" role="region" aria-label="RadarChart props" tabIndex={0}>

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `config` | `SeriesConfig` | Required | Series or category labels, colors and formatting. |
| `interaction` | `ChartInteractionConfig` | Family focus | Shared legend and supported mark actions; eligibility remains explicit. |
| `frameProps` | HTML frame attributes | — | Styles, handlers, data attributes and ref for the outer HTML frame. |
| `data` | `Row[]` | — | Category rows used by explicit axes and series. |
| `animate` | `boolean \| RadarAnimation` | `false` | Center-out entrance for default polygons; respects reduced motion. |
| `cx` / `cy` | `number \| string` | `"50%"` | Native polar center. |
| `outerRadius` | `number \| string` | `"80%"` | Plot radius; these components reserve label space with `"68%"`. |
| `aria-label` / `aria-labelledby` | `string` | — | Accessible plot name; does not add spoke keyboard inspection. |
| `children` | `ReactNode` | Required | Explicit polar axes, grid, series and tooltip. |

</div>

`RadarAnimation` accepts `revealDurationMs` (default `1000`), `revealEasing` (default `"easeOut"`) and `hoverTransition` (shared spring). See [Recharts RadarChart](https://recharts.github.io/en-US/api/RadarChart/).

### RadarChart.Series

String `dataKey` values identify config entries. Use `seriesKey` for numeric keys or accessors with visibility or selection.

<div className="line-props-scroll" role="region" aria-label="RadarChart.Series props" tabIndex={0}>

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `dataKey` | `string \| number \| ((row: Row) => unknown)` | — | Value field or native accessor; supplied for both profiles here. |
| `seriesKey` | `string` | String `dataKey` | Metadata, visibility and selection identity. |
| `material` | `"clay" \| "glow"` | Omitted | Finish on default polygons; consumer rendering takes precedence. |
| `stroke` / `fill` | `string` | Config color | Override outline or fill independently. |
| `fillOpacity` | `number` | SVG default `1` | These overlapping profiles explicitly use `0.18`. |
| `dot` | `boolean` or native dot props / renderer | `false` | Optional native category marks. |
| `activeDot` | `boolean` or native dot props / renderer | Kind active marker | Native inspected-category marker; independent of selection. |
| `hide` | `boolean` | `false` | Suppresses series paint and inspection while preserving full-data layout; chart visibility also applies. |
| `shape` | Native element or renderer | Kind default polygon | Consumer-owned shape bypasses material and center-out masking. |

</div>

See [Recharts Radar](https://recharts.github.io/en-US/api/Radar/).

## Shared components

Configure profile colors, radial scales and selection controls with these components.

| Component | Purpose |
| --- | --- |
| [Chart frame](/docs/chart-components/chart/) | Share colors, formatting and series visibility. |
| [SeriesConfig](/docs/chart-components/series-config/) | Name series and define their colors and value formats. |
| [Axes and grid](/docs/chart-components/axes-grid/) | Label scales and add comparison guides. |
| [Legend](/docs/chart-components/legend/) | Identify series and focus by dimming other marks. |
| [Tooltip](/docs/chart-components/tooltip/) | Show values for the inspected mark. |

Place custom HTML controls or status text in the family’s `Content` part. Keep function/numeric data accessors paired with explicit `seriesKey` metadata.
