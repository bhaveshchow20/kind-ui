## Usage

`Root` supplies series metadata. Compute ordered rows once, then pass the same rows to `WaterfallChart` and `WaterfallConnectors`. `WaterfallSeries` draws floating ranges; native `Cell` children supply increase, decrease and checkpoint colors. The first Code tab is a complete named client component with its cash-flow inputs and semantic tooltip.

```tsx title="Composition"
<Chart.Root config={config}>
  <Chart.ResponsiveContainer width="100%" height={280}>
    <Chart.WaterfallChart data={data} layout="vertical" animate accessibilityLayer>
      <Chart.XAxis type="number" />
      <Chart.YAxis type="category" dataKey="id" />
      <Chart.WaterfallConnectors data={data} position="middle" />
      <Chart.WaterfallSeries>
        {data.map((row) => <Chart.Cell key={row.id} fill={row.kind !== "delta" ? "#733bff" : (row.value ?? 0) < 0 ? "#be123c" : "#15803d"} />)}
      </Chart.WaterfallSeries>
      <Chart.Tooltip filterNull={false} content={(tooltip) => {
        const row = data.find((row) => row.id === String(tooltip.label));
        return tooltip.active && row ? <div>{row.label}: {row.value ?? "Unknown"} ($k); balance {row.balance ?? "Unknown"} ($k)</div> : null;
      }} />
    </Chart.WaterfallChart>
  </Chart.ResponsiveContainer>
</Chart.Root>
```

Keep one unstacked series on these axes. `layout="vertical"` is Recharts terminology for horizontal bars. Use `id` on the category axis and format it into a readable label. The application owns arithmetic inputs, units, axis domains and tooltip content. The example's color key labels step roles; it does not toggle individual contributions, which would change the chain's meaning.

## Inputs and checkpoints

`computeWaterfallData(entries, initialBalance = 0)` returns new rows in input order without mutating entries. Values here are USD thousands.

<div className="line-props-scroll" role="region" aria-label="Waterfall input kinds" tabIndex={0}>

| Kind | Supplied value | Behavior |
| --- | --- | --- |
| `"start"` | `number \| null` | Draw zero to value; establish an absolute opening balance. |
| `"delta"` | `number \| null` | Draw previous balance to previous balance plus the signed change. |
| `"subtotal"` | None | Draw zero to current balance without adding it again or resetting it. |
| `"total"` | `number \| null` | Establish an explicit absolute checkpoint. |
| `"end"` | `number \| null` | Establish an explicit closing checkpoint; never infer a final sum. |

</div>

The opening $120k plus sales $75k and refunds −$15k gives the $180k subtotal. Costs −$65k and tax −$20k leave $95k. The closing entry explicitly supplies $95k. Kind names express intent, with no positional restrictions; a checkpoint may intentionally disagree with the preceding computed balance.

Connectors join adjacent known balances only when they agree. They do not bridge missing geometry or connect to a differing checkpoint. Place them before the bars so their category-center endpoints sit underneath. When subsetting data, subset both chart and connectors together.

## Missing and zero values

A `null` change makes the balance unknown until a known checkpoint restores it. Later changes retain their original values even while their geometry is unknown. A `null` checkpoint also establishes an unknown balance. Pass `null` as the second function argument when the opening balance is unknown: `computeWaterfallData(entries, null)`.

<ChartExample id="waterfall-missing" />

Pending is unknown, so Fees has a known −$10k change with unknown endpoints. Audited restores the balance to $105k. No change is a real zero delta: its range is `[105, 105]`, with no invented minimum bar size. Inspect that category with the tooltip; the hidden data alternative also preserves zero and unknown values.

Values must be finite numbers or explicit `null`; omission is invalid except for subtotals, which must omit `value`. Empty or duplicate IDs, unknown kinds, nonfinite values, supplied subtotal values and arithmetic overflow throw.

## Motion and inspection

`WaterfallChart` is the public alias of `BarChart`. `animate` enables chart-owned Motion reveal from the numeric zero baseline; it does not animate the arithmetic or increment contributions sequentially. Pointer or keyboard interaction interrupts the reveal, and reduced motion disables it. Native per-series Recharts animation stays disabled.

The composed tooltip uses the row's `value`, `start` and `balance`; a default native range tooltip would report endpoints instead of the signed contribution. `filterNull={false}` permits inspection of unknown steps. Focus the plot and use arrow keys to inspect categories; Escape dismisses the tooltip. Range bars do not qualify for Bar's scalar category paint emphasis. These examples do not request it or toggle contributions.

## API reference

Use public `@kind-ui/charts` exports. Kind adds metadata, motion and the ordered data helper to explicit Recharts composition. Native axes, cells, grid and reference lines retain upstream geometry semantics.

### computeWaterfallData

<div className="line-props-scroll" role="region" aria-label="computeWaterfallData parameters" tabIndex={0}>

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `entries` | `readonly WaterfallEntry[]` | Required | Ordered inputs with unique nonempty `id`, `label`, `kind` and kind-specific value. |
| `initialBalance` | `number \| null` | `0` | Balance before the first entry; `null` means unknown. |

</div>

Returns `WaterfallDatum[]`. Each row retains `id`, `label` and `kind`. `value` is the original change/checkpoint or computed subtotal; `start`, `end` and `balance` are directed endpoints and running balance. `range` is the sorted `[number, number]` pair for native bars, or `null` when geometry is unknown. Use `value` to determine change direction; sorting the range loses the sign.

### Root

<div className="line-props-scroll" role="region" aria-label="Waterfall Root props" tabIndex={0}>

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `config` | `SeriesConfig` | Required | Metadata and color keyed by `range` in these examples. |
| `visibleSeries` | `readonly string[]` | All series | Whole-series visibility; does not recompute inputs. |
| `onVisibleSeriesChange` | `(keys: string[]) => void` | — | Consumer-owned legend selection callback. |

</div>

To hide the whole flow, use matching visibility identities for bars and connectors. Individual contribution filtering requires the application to decide and recompute the intended chain.

### WaterfallChart

<div className="line-props-scroll" role="region" aria-label="WaterfallChart props" tabIndex={0}>

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `data` | `WaterfallDatum[]` | — | Computed or host-owned range rows. |
| `layout` | `"horizontal" \| "vertical"` | `"horizontal"` | Vertical bars or horizontal bars, respectively. |
| `animate` | `boolean \| BarAnimation` | `false` | Chart-owned motion with reduced-motion handling. |
| `barCategoryGap` | `number \| string` | `"10%"` | Native category spacing; these components use `"32%"`. |
| `accessibilityLayer` | `boolean` | `true` in Recharts | Keyboard category inspection; set explicitly here. |
| `aria-label` / `aria-labelledby` | `string` | — | Accessible plot name, including units. |

</div>

`BarAnimation` shares `LineAnimation`: `revealDurationMs` defaults to `1000`, `revealEasing` to `[0.25, 0.1, 0.25, 1]`, and `hoverTransition` controls supported inspection motion. See [Recharts BarChart](https://recharts.github.io/en-US/api/BarChart/).

### WaterfallSeries

<div className="line-props-scroll" role="region" aria-label="WaterfallSeries props" tabIndex={0}>

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `seriesKey` | `string` | `"range"` | Metadata and controlled visibility identity. |
| `material` | `"plain" \| "paper" \| "clay" \| "glow"` | `"plain"` | Finish on native rectangles; custom shapes/filters retain ownership. |
| `hide` | `boolean` | `false` | Hide all bars; pass the same value to connectors. |
| `radius` | `number \| [number, number, number, number]` | `0` | Native rectangle corner radius. |
| `children` | `ReactNode` | — | Native `Cell` and `LabelList` composition. |

</div>

Binds `dataKey="range"` and `minPointSize={0}`. It excludes and rejects `data`, `dataKey`, `stackId` and `minPointSize`. Native shapes, active bars, events and refs remain available. See [Recharts Bar](https://recharts.github.io/en-US/api/Bar/) and [Cell](https://recharts.github.io/en-US/api/Cell/).

### WaterfallConnectors

<div className="line-props-scroll" role="region" aria-label="WaterfallConnectors props" tabIndex={0}>

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `data` | `readonly WaterfallDatum[]` | Required | The same ordered rows supplied to the chart. |
| `seriesKey` | `string` | `"range"` | Match the bars' visibility identity. |
| `hide` | `boolean` | `false` | Match native bar hide state. |
| `position` | `"start" \| "middle" \| "end"` | `"middle"` in Recharts | Category-band alignment; set `"middle"` explicitly here. |
| `xAxisId` / `yAxisId` | `string \| number` | `0` | Match the series' axes. |
| `strokeDasharray` | `string` | `"3 3"` | Connector dash pattern. |
| `zIndex` | `number` | `100` | Native layer order; endpoints sit under bars. |

</div>

Uses native `ReferenceLine` segments with no pointer capture. `x`, `y`, `segment` and `children` are excluded. See [Recharts ReferenceLine](https://recharts.github.io/en-US/api/ReferenceLine/).
