## Usage

Supply your own data and accessible name. Both installation paths use this local component.

```tsx title="Dashboard.tsx"
import { WaterfallChart, WaterfallSeries } from "@/components/charts/waterfall-chart";

const data = [{ label: "Start", value: 100, kind: "total" as const }, { label: "Change", value: -20 }];
const config = { sales: { label: "Sales", color: "#733bff" } };

export function Dashboard() {
  return <WaterfallChart config={config} data={data} aria-label="Chart data"><WaterfallSeries seriesKey="sales" /></WaterfallChart>;
}
```

The local file owns presentation defaults. Set `config` to use its frame; omit it when composing inside your own `Root`. Series and marks remain explicit children. Line, Heatmap and ActivityRings supply their own context.

See the [npm core installation](/docs/installation/#npm-core) for direct package imports. The API reference below describes the underlying core parts; the editable wrapper also accepts `config`, `rootProps`, `height`, `width` and optional `legend` where it supplies a frame.

## Inputs and checkpoints

Each row describes a change or an absolute checkpoint.

<div className="line-props-scroll" role="region" aria-label="Waterfall input kinds" tabIndex={0}>

| Kind | Supplied value | Behavior |
| --- | --- | --- |
| `"start"` | `number \| null` | Draw zero to value; establish an absolute opening balance. |
| `"delta"` | `number \| null` | Draw previous balance to previous balance plus the signed change. |
| `"subtotal"` | None | Draw zero to current balance without adding it again or resetting it. |
| `"total"` | `number \| null` | Establish an explicit absolute checkpoint. |
| `"end"` | `number \| null` | Establish an explicit closing checkpoint; never infer a final sum. |

</div>

Place connectors before bars and pass both the same rows. Checkpoints set an explicit balance.

## Missing and zero values

A null change makes the balance unknown until a known checkpoint restores it.

## API reference

Prepare ordered balances, then configure bars and connectors.

### computeWaterfallData

<div className="line-props-scroll" role="region" aria-label="computeWaterfallData parameters" tabIndex={0}>

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `entries` | `readonly WaterfallEntry[]` | Required | Ordered inputs with unique nonempty `id`, `label`, `kind` and kind-specific value. |
| `initialBalance` | `number \| null` | `0` | Balance before the first entry; `null` means unknown. |

</div>

Returns `WaterfallDatum[]` with `value`, `start`, `balance` and sorted `range` endpoints. Use `value` to distinguish positive and negative changes.

### WaterfallChart

<div className="line-props-scroll" role="region" aria-label="WaterfallChart props" tabIndex={0}>

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `data` | `WaterfallDatum[]` | — | Computed or host-owned range rows. |
| `layout` | `"horizontal" \| "vertical"` | `"horizontal"` | Vertical bars or horizontal bars, respectively. |
| `animate` | `boolean \| BarAnimation` | `false` | Chart-owned motion with reduced-motion handling. |
| `barCategoryGap` | `number \| string` | `"10%"` | Native category spacing; these components use `"32%"`. |
| `accessibilityLayer` | `boolean` | `true` in Recharts | Keyboard category inspection; set explicitly here. |
| `aria-label` / `aria-labelledby` | `string` | — | Accessible plot name, including units. |

</div>

`BarAnimation` shares `LineAnimation`: default duration `1000`, easing `[0.25, 0.1, 0.25, 1]`, and supported inspection `hoverTransition`. See [Recharts BarChart](https://recharts.github.io/en-US/api/BarChart/).

### WaterfallSeries

<div className="line-props-scroll" role="region" aria-label="WaterfallSeries props" tabIndex={0}>

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `seriesKey` | `string` | `"range"` | Metadata and controlled visibility identity. |
| `material` | `"clay" \| "glow"` | Omitted | Finish on native rectangles; custom shapes/filters retain ownership. |
| `hide` | `boolean` | `false` | Hide all bars; pass the same value to connectors. |
| `radius` | `number \| [number, number, number, number]` | `0` | Native rectangle corner radius. |
| `children` | `ReactNode` | — | Native `Cell` and `LabelList` composition. |

</div>

Binds `range` with zero minimum size; rejects `data`, `dataKey`, `stackId` and `minPointSize`. Native shapes/events remain available. See [Recharts Bar](https://recharts.github.io/en-US/api/Bar/) and [Cell](https://recharts.github.io/en-US/api/Cell/).

### WaterfallConnectors

<div className="line-props-scroll" role="region" aria-label="WaterfallConnectors props" tabIndex={0}>

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `data` | `readonly WaterfallDatum[]` | Required | The same ordered rows supplied to the chart. |
| `seriesKey` | `string` | `"range"` | Match the bars' visibility identity. |
| `hide` | `boolean` | `false` | Match native bar hide state. |
| `position` | `"start" \| "middle" \| "end"` | `"middle"` in Recharts | Category-band alignment; set `"middle"` explicitly here. |
| `xAxisId` / `yAxisId` | `string \| number` | `0` | Match the series' axes. |
| `strokeDasharray` | `string` | `"3 3"` | Connector dash pattern. |
| `zIndex` | `number` | `100` | Native layer order; endpoints sit under bars. |

</div>

See [Recharts ReferenceLine](https://recharts.github.io/en-US/api/ReferenceLine/).
