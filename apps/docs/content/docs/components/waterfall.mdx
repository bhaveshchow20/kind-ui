## How it works

`computeWaterfallData` turns entries into native range bars and connectors. Opening sets 80; sales adds 50 and costs subtracts 160, reaching −30. The subtotal records that balance without adding it again. A refund subtracts 12 and recovery adds 82, reaching 40 and an explicit closing checkpoint records 40.

A missing value makes the running balance unknown until an explicit start/end checkpoint restores it. The helper does not repair business arithmetic. Native Cells color increases, decreases and checkpoints, while the data table exposes all computed balances. Narrow screens can scroll the plot.
