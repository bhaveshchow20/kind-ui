## How it works

`hours` is the magnitude field. `id` is the category name and metadata identity. The example filters rows by its included IDs, renders Cells from that same filtered array, and sums those rows for the center total. The data table computes shares against the included total.

`Tooltip.itemKey` maps payload `id` to config. All four categories have measured allocations. Hiding every category yields an empty chart and an explicit zero-total status.

Automatic sector emphasis preserves data and totals. The fixed 52% hole uses native `innerRadius`; there is no separate DonutChart export. Native `paddingAngle` controls sector gaps. The curated sectors use Paper; the [materials guide](/docs/guides/materials/) documents the wider primitive contracts and limits.
