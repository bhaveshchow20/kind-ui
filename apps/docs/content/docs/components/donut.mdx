## How it works

`hours` is the magnitude field. `id` is the category name and metadata identity. The example filters rows by its included IDs, renders Cells from that same filtered array, and sums those rows for the center total. The data table computes shares against the included total.

`Tooltip.itemKey` maps payload `id` to config. The zero-hour category remains in the table even though it has no measurable arc. Hiding every category yields an empty chart and an explicit zero-total status.

Automatic sector emphasis preserves data and totals. Changing the hole uses native `innerRadius`; there is no separate DonutChart export. Native `paddingAngle` controls sector gaps. Plain and Paper are demonstrated here; the [materials guide](/docs/guides/materials/) documents the wider primitive contracts and limits.
