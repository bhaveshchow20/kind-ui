## Usage

`HistogramChart` requires `config`, an accessible name and explicit children. Add the parts you need; omitted parts stay absent. Set plot dimensions on the chart, shared actions on `interaction`, and outer HTML attributes on `frameProps`.

Use `binHistogram` to prepare numeric bins for `HistogramChart.Series`.

```tsx title="Composition sketch"
import { HistogramChart } from "@kind-ui/charts";

<HistogramChart config={config} height={280} aria-label="Histogram values" bins={result.bins} measure="count" animate accessibilityLayer>
  <HistogramChart.XAxis />
  <HistogramChart.YAxis />
  <HistogramChart.Grid vertical={false} />
  <HistogramChart.Series />
  <HistogramChart.Tooltip />
</HistogramChart>
```

Bar height shows count; width shows the interval. Bins include the lower edge, and the final bin includes the upper edge.

## API reference

Use `HistogramChart.XAxis` and `HistogramChart.YAxis` to format ticks on the numeric scales.

### binHistogram

<div className="line-props-scroll" role="region" aria-label="binHistogram parameters" tabIndex={0}>

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `config` | `SeriesConfig` | Required | Series or category labels, colors and formatting. |
| `aria-label` / `aria-labelledby` | `string` | One required | Accessible chart name. |
| `children` | `ReactNode` | Required | Explicit family parts; omitted parts stay absent. |
| `interaction` | `ChartInteractionConfig` | Family focus | Shared legend and supported mark actions; eligibility remains explicit. |
| `frameProps` | HTML frame attributes | — | Styles, handlers, data attributes and ref for the outer HTML frame. |
| `samples` | `readonly (number \| null \| undefined)[]` | Required | Raw observations; missing, nonfinite and out-of-range values are counted separately. |
| `edges` | `readonly number[]` | Required | At least two finite, strictly increasing edges with finite positive widths. Invalid edges throw. |

</div>

Returns `bins` plus accepted, missing, nonfinite and out-of-range sample counts.

Pre-aggregated bins may have gaps. Bounds must be ordered, nonoverlapping and finite with positive finite widths; counts and their total must be nonnegative safe integers.

### HistogramChart

<div className="line-props-scroll" role="region" aria-label="HistogramChart props" tabIndex={0}>

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `bins` | `readonly HistogramBin[]` | Required | Validated intervals; their first lower and final upper bounds define the horizontal domain. |
| `measure` | `"count" \| "density"` | Required | Count height or normalized probability density. Numerically unrepresentable density throws. |
| `animate` | `boolean \| BarAnimation` | `false` | Reuses chart-owned Bar entrance and reduced-motion handling. Options include `revealDurationMs`, `revealEasing` and `hoverTransition`. |
| `accessibilityLayer` | `boolean` | `true` in Recharts | Arrow-key inspection; set explicitly in these components. |
| `margin` | `{ top?: number; right?: number; bottom?: number; left?: number }` | `5` each side | Plot spacing. |
| `children` | `ReactNode` | — | Explicit histogram series, grid and tooltip. |

</div>

Owns data, vertical layout, scales and spacing. See [XAxis](https://recharts.github.io/en-US/api/XAxis/), [YAxis](https://recharts.github.io/en-US/api/YAxis/) and [BarChart](https://recharts.github.io/en-US/api/BarChart/) for presentation options.

### HistogramChart.Series

<div className="line-props-scroll" role="region" aria-label="HistogramChart.Series props" tabIndex={0}>

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `seriesKey` | `string` | `"count"` | Chart metadata and visibility identity; internal `dataKey` is owned. |
| `material` | `"clay" \| "glow"` | Omitted | Finish on corrected bin rectangles. |
| `shape` | `(props: HistogramShapeProps) => ReactElement` | — | Native bar shape props with corrected numeric `x`, `width` and original `bin`; custom geometry becomes consumer-owned. |
| `fill` / `stroke` | `string` | Config color / unset | Explicit paint overrides. |
| `hide` | `boolean` | `false` | Suppresses series paint and inspection while preserving full-data layout; chart visibility also applies. |

</div>

Use inside `HistogramChart`; stacking and custom bar sizing are unsupported. See [Recharts Bar](https://recharts.github.io/en-US/api/Bar/).

## Shared components

Use chart config for the measure’s color and Tooltip for bin values.

| Component | Purpose |
| --- | --- |
| [Chart frame](/docs/chart-components/chart/) | Share colors, formatting and series visibility. |
| [SeriesConfig](/docs/chart-components/series-config/) | Name series and define their colors and value formats. |
| [Axes and grid](/docs/chart-components/axes-grid/) | Label scales and add comparison guides. |
| [Tooltip](/docs/chart-components/tooltip/) | Show values for the inspected mark. |

Place custom HTML controls or a data alternative in the family’s `Content` part. Keep function/numeric data accessors paired with explicit `seriesKey` metadata.
