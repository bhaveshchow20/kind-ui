## How it works

Six caller-supplied response-time intervals use unequal widths and density: count divided by total count and interval width. Rectangle area therefore represents probability, with height in ms⁻¹.

The complete table preserves interval endpoints, counts and densities. The curated Paper composition, exact bins and animation setting are reproduced by Copy prompt, Code and Download example. For raw samples and explicit edge/missing-value rules, see the [data helpers](/docs/reference/data/).
