## Usage

Open **Code** above for the complete example, including data and imports.

Add one `BarSeries` per measure. Use `stackId` for stacks and `layout="vertical"` for horizontal bars.

```tsx title="Composition sketch"
<Chart.Root config={config} defaultVisibleSeries={Object.keys(config)}>
  <Chart.Legend />
  <Chart.ResponsiveContainer width="100%" height={280}>
    <Chart.BarChart data={data} animate accessibilityLayer aria-label="Pickup orders by location">
      <Chart.CartesianGrid vertical={false} />
      <Chart.XAxis dataKey="period" />
      <Chart.YAxis />
      <Chart.BarSeries dataKey="orders" radius={[5, 5, 0, 0]} />
      <Chart.Tooltip />
    </Chart.BarChart>
  </Chart.ResponsiveContainer>
</Chart.Root>
```

Place the legend outside the plot. `defaultVisibleSeries` enables its visibility buttons.

## Category emphasis

Set `emphasis="category"` to dim other categories during hover or keyboard inspection.

See `BarSeries` below for supported values and shapes.

## Series patterns

Add a pattern to distinguish a series. Its legend swatch follows the same config.

```tsx
const config = {
  orders: { label: "Orders", color: "#733bff", pattern: { kind: "hatch" } },
} satisfies Chart.SeriesConfig;

// Inside the chart:
<Chart.BarSeries dataKey="orders" />
```

Override the config with `BarSeries.pattern`; use `pattern={false}` to turn it off.

<Callout title="Note">Explicit `fill`, Cells and custom shapes override the pattern. Keep labels and an accessible data table alongside patterns.</Callout>

## Projected bars

In the copied Bar example, mark projected rows in `data`. Then use the same rule for the series and tooltip:

```tsx
const data = [
  { period: "North", orders: 124 },
  { period: "East", orders: 186, projected: true },
];
type ProjectionRow = (typeof data)[number];
const isProjected = (row: ProjectionRow) => row.projected === true;

<Chart.BarSeries dataKey="orders"
  projection={{ isProjected, pattern: { kind: "stripe" } }} />
<Chart.Tooltip content={(tooltip) => (
  <Chart.TooltipContent tooltip={tooltip}
    isProjected={(entry) => isProjected(entry.payload)} />
)} />
```

<Callout title="Note">This styles supplied values; it does not calculate a forecast. Label projected rows in your accessible data table.</Callout>

## API reference

Use these props to configure bars, stacks and presentation.

### BarChart

Use inside `Root` and a sized `ResponsiveContainer`.

<div className="line-props-scroll" role="region" aria-label="BarChart props" tabIndex={0}>

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `data` | `Row[]` | — | Consumer-owned category observations. |
| `animate` | `boolean \| BarAnimation` | `false` | Reveal from numeric zero or nearest domain edge; respects reduced motion. |
| `emphasis` | `"none" \| "category"` | `"none"` | Opt in to eligible category comparisons. |
| `layout` | `"horizontal" \| "vertical"` | `"horizontal"` | `"horizontal"` draws columns; `"vertical"` draws horizontal bars. |
| `barGap` | `number \| string` | `4` | Gap between grouped bars. |
| `barCategoryGap` | `number \| string` | `"10%"` | Space between category groups. |
| `stackOffset` | `"none" \| "expand" \| "wiggle" \| "silhouette" \| "sign" \| "positive"` | `"none"` | Native stack calculation; use `"sign"` for separate positive/negative stacks. |
| `accessibilityLayer` | `boolean` | `true` in Recharts | Native keyboard inspection; explicit in these components. |
| `aria-label` / `aria-labelledby` | `string` | — | Accessible plot name. |
| `margin` | `{ top?: number; right?: number; bottom?: number; left?: number }` | `5` each side | Space around plot parts. |
| `children` | `ReactNode` | — | Explicit axes, series, grid and tooltip. |

</div>

`BarAnimation` accepts `revealDurationMs` (default `1000`), `revealEasing` and `hoverTransition`. See [Recharts BarChart](https://recharts.github.io/en-US/api/BarChart/).

### BarSeries

String value keys identify config entries; controlled numeric keys or accessors require `seriesKey`.

<div className="line-props-scroll" role="region" aria-label="BarSeries props" tabIndex={0}>

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `dataKey` | `string \| number \| ((row: Row) => unknown)` | Required | Value field or accessor. |
| `seriesKey` | `string` | String `dataKey` | Metadata and visibility identity. |
| `stackId` | `string \| number` | — | Stack series with matching axis IDs. |
| `material` | `"clay" \| "glow"` | Omitted | Native-rectangle finish; custom paint takes precedence. |
| `emphasisKey` | `(payload: unknown) => string \| number \| undefined` | — | Unique category identity; does not make invalid values or custom shapes eligible. |
| `radius` | `number \| [number, number, number, number]` | `0` | Native corner rounding: top-left, top-right, bottom-right, bottom-left. |
| `maxBarSize` | `number` | — | Limit each bar's thickness. |
| `fill` | `string` | Config color | Native fill override; Cells can customize individual bars. |
| `hide` | `boolean` | `false` | Native hide and Root selection both apply. |
| `children` | `ReactNode` | — | Native Cells, LabelList and ErrorBar composition. |

</div>

<Callout title="Category emphasis">Use chart-level rows, string value keys, unique category IDs and native rectangles. Missing, zero/baseline or range values, per-series data, custom shapes and non-boolean `activeBar` disable this effect.</Callout>

Custom shapes and filters can override materials. See [Recharts Bar](https://recharts.github.io/en-US/api/Bar/) and [material support](/docs/guides/materials/).
