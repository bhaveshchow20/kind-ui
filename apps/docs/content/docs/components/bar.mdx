## Usage

`Root` supplies metadata; `ResponsiveContainer` sizes the plot. Compose axes, `BarSeries` and `Tooltip` inside `BarChart`, which owns motion and inspection.

```tsx title="Composition"
<Chart.Root config={config}>
  <Chart.Legend />
  <Chart.ResponsiveContainer width="100%" height={280}>
    <Chart.BarChart data={data} animate accessibilityLayer aria-label="Pickup orders by location">
      <Chart.CartesianGrid vertical={false} />
      <Chart.XAxis dataKey="period" />
      <Chart.YAxis />
      <Chart.BarSeries dataKey="orders" radius={[5, 5, 0, 0]} />
      <Chart.Tooltip />
    </Chart.BarChart>
  </Chart.ResponsiveContainer>
</Chart.Root>
```

Bar uses explicit composition. Place `Legend` outside the plot; pair Root visibility with its callback for toggles.

## Category emphasis

`BarChart emphasis="category"` dims other categories during hover or keyboard inspection. `Root emphasis="none"` disables it. Touch inspection does not activate hover emphasis.

Eligibility requires compatible values and marks in every visible series; see `BarSeries` below.

## API reference

Focused props for explicit composition. Recharts owns grouping, stacking and axis geometry.

### Root

Shares metadata and controlled visibility.

<div className="line-props-scroll" role="region" aria-label="Root props" tabIndex={0}>

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `config` | `SeriesConfig` | Required | Labels, colors and optional value formatters keyed by series. |
| `visibleSeries` | `readonly string[]` | All series | Consumer-owned selection. |
| `onVisibleSeriesChange` | `(keys: string[]) => void` | — | Enables legend buttons; requires `visibleSeries`. |
| `emphasis` | `"auto" \| "none"` | `"auto"` | Allows supported emphasis; category emphasis still requires chart opt-in and eligible peers. |

</div>

### BarChart

Use inside `Root` and a sized `ResponsiveContainer`.

<div className="line-props-scroll" role="region" aria-label="BarChart props" tabIndex={0}>

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `data` | `Row[]` | — | Consumer-owned category observations. |
| `animate` | `boolean \| BarAnimation` | `false` | Reveal from numeric zero or nearest domain edge; respects reduced motion. |
| `emphasis` | `"none" \| "category"` | `"none"` | Opt in to eligible category comparisons. |
| `layout` | `"horizontal" \| "vertical"` | `"horizontal"` | `"horizontal"` draws columns; `"vertical"` draws horizontal bars. |
| `barGap` | `number \| string` | `4` | Gap between grouped bars. |
| `barCategoryGap` | `number \| string` | `"10%"` | Space between category groups. |
| `stackOffset` | `"none" \| "expand" \| "wiggle" \| "silhouette" \| "sign" \| "positive"` | `"none"` | Native stack calculation; use `"sign"` for separate positive/negative stacks. |
| `accessibilityLayer` | `boolean` | `true` in Recharts | Native keyboard inspection; explicit in these components. |
| `aria-label` / `aria-labelledby` | `string` | — | Accessible plot name. |
| `margin` | `{ top?: number; right?: number; bottom?: number; left?: number }` | `5` each side | Space around plot parts. |
| `children` | `ReactNode` | — | Explicit axes, series, grid and tooltip. |

</div>

Entrance stops on interaction or data/geometry changes. Remount to replay. `BarAnimation` accepts `revealDurationMs` (default `1000`), `revealEasing` and `hoverTransition`. See [Recharts BarChart](https://recharts.github.io/en-US/api/BarChart/).

### BarSeries

String value keys identify config entries; controlled numeric keys or accessors require `seriesKey`.

<div className="line-props-scroll" role="region" aria-label="BarSeries props" tabIndex={0}>

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `dataKey` | `string \| number \| ((row: Row) => unknown)` | Required | Value field or accessor. |
| `seriesKey` | `string` | String `dataKey` | Metadata and visibility identity. |
| `stackId` | `string \| number` | — | Stack series with matching axis IDs. |
| `material` | `"plain" \| "paper" \| "clay" \| "glow"` | `"plain"` | Native-rectangle finish; custom paint takes precedence. |
| `emphasisKey` | `(payload: unknown) => string \| number \| undefined` | — | Unique category identity; does not make invalid values or custom shapes eligible. |
| `radius` | `number \| [number, number, number, number]` | `0` | Native corner rounding: top-left, top-right, bottom-right, bottom-left. |
| `maxBarSize` | `number` | — | Limit each bar's thickness. |
| `fill` | `string` | Config color | Native fill override; Cells can customize individual bars. |
| `hide` | `boolean` | `false` | Native hide and Root selection both apply. |
| `children` | `ReactNode` | — | Native Cells, LabelList and ErrorBar composition. |

</div>

Category emphasis requires native rectangles, chart-level rows, string value keys and finite non-baseline values. Use unique string categories or unique, defined `emphasisKey` results for every row.

Missing, null, zero/baseline or range values, per-series data, custom shapes and non-boolean `activeBar` disable category emphasis for the chart. Hidden peers do not block eligibility.

Finishes are static. Native per-series animation is disabled. Custom `shape`, `filter` or non-boolean `activeBar` owns paint. See [Recharts Bar](https://recharts.github.io/en-US/api/Bar/) and [material support](/docs/guides/materials/).

### Legend

Place outside `ResponsiveContainer`. Root visibility and its callback enable keyboard-operable toggles; otherwise items are labels.

<div className="line-props-scroll" role="region" aria-label="Legend props" tabIndex={0}>

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `hideIcon` | `boolean` | `false` | Use swatches instead of configured icons. |
| `emphasis` | `"none" \| "series"` | `"none"` | Requests series emphasis on hover or focus; supported paint behavior is family-specific. |

</div>

### Tooltip

Hidden series are excluded. Arrow keys inspect categories; Escape dismisses inspection.

<div className="line-props-scroll" role="region" aria-label="Tooltip props" tabIndex={0}>

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `cursor` | Native cursor props or renderer | `false` | Optional inspection guide. |
| `maxWidth` | `number` | `180` | Tooltip width bound in pixels. |

</div>

See [Recharts Tooltip](https://recharts.github.io/en-US/api/Tooltip/).

### XAxis

Category axis for columns; use `type="number"` for horizontal bars.

<div className="line-props-scroll" role="region" aria-label="XAxis props" tabIndex={0}>

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `dataKey` | `string \| number \| ((row: Row) => unknown)` | — | Category label field or accessor. |
| `axisLine` / `tickLine` | Native line props | `true` | Axis and tick strokes; shown components disable both. |
| `tickMargin` | `number` | `5` | Label breathing room; columns use `16`. |

### YAxis

Numeric axis for columns; use `type="category"` and a `dataKey` for horizontal bars.

<div className="line-props-scroll" role="region" aria-label="YAxis props" tabIndex={0}>

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `domain` | Native domain | `[0, "auto"]` | Numeric scale bounds. |
| `tickFormatter` | `(value: number, index: number) => string` | — | Format tick labels. |
| `width` | `number \| "auto"` | `60` | Space reserved for labels; columns use `80`, horizontal bars use `160`. |

</div>

See [Recharts YAxis](https://recharts.github.io/en-US/api/YAxis/).
