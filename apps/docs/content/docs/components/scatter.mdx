## Usage

Supply your own data and accessible name. Both installation paths use this local component.

```tsx title="Dashboard.tsx"
import { ScatterChart, ScatterSeries, XAxis, YAxis } from "@/components/charts/scatter-chart";

const data = [{ x: 10, y: 20 }, { x: 20, y: 35 }];
const config = { sales: { label: "Sales", color: "#733bff" } };

export function Dashboard() {
  return <ScatterChart config={config}  aria-label="Chart data"><XAxis type="number" dataKey="x" /><YAxis type="number" dataKey="y" /><ScatterSeries data={data} seriesKey="sales" /></ScatterChart>;
}
```

The local file owns presentation defaults. Set `config` to use its frame; omit it when composing inside your own `Root`. Series and marks remain explicit children. Line, Heatmap and ActivityRings supply their own context.

See the [npm core installation](/docs/installation/#npm-core) for direct package imports. The API reference below describes the underlying core parts; the editable wrapper also accepts `config`, `rootProps`, `height`, `width` and optional `legend` where it supplies a frame.

## API reference

Configure numeric dimensions, point symbols and tooltip values.

### ScatterChart

<div className="line-props-scroll" role="region" aria-label="ScatterChart props" tabIndex={0}>

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `animate` | `boolean \| ScatterAnimation` | `false` | In-place entrance fade and shared tooltip motion; respects reduced motion. |
| `accessibilityLayer` | `boolean` | `true` in Recharts | Native first-series keyboard inspection; set explicitly here. |
| `margin` | `{ top?: number; right?: number; bottom?: number; left?: number }` | `5` each | Plot spacing for axes and marks. |
| `children` | `ReactNode` | — | Explicit axes, grid, series and Scatter tooltip. |
| `aria-label` / `aria-labelledby` | `string` | — | Accessible plot name. |

</div>

See [Recharts ScatterChart](https://recharts.github.io/en-US/api/ScatterChart/).

<Callout title="Server rendering">At the pinned Recharts version, fixed-size server rendering omits Scatter marks. Include a server-rendered data alternative or summary.</Callout>

### ScatterSeries

<div className="line-props-scroll" role="region" aria-label="ScatterSeries props" tabIndex={0}>

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `data` | `Row[]` | — | Native point records; axis keys read these records. |
| `seriesKey` | `string` | String `dataKey` | Config and visibility identity; use explicitly for cohorts. |
| `shape` | `"circle" \| "cross" \| "diamond" \| "square" \| "star" \| "triangle" \| "wye"` or native custom shape | `"circle"` | Built-in symbol or consumer-owned renderer. |
| `material` | `"clay" \| "glow"` | Omitted | Finish for built-in symbols, preserving native geometry. |
| `fill` | `string` | Config color when identified | Explicit color overrides metadata. |
| `hide` | `boolean` | `false` | Suppresses paint and inspection while preserving coordinates; Root visibility also applies. |
| `xAxisId` / `yAxisId` / `zAxisId` | `string \| number` | `0` | Native axis association. |

</div>

See [Recharts Scatter](https://recharts.github.io/en-US/api/Scatter/).

### ScatterTooltip

<div className="line-props-scroll" role="region" aria-label="ScatterTooltip props" tabIndex={0}>

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `pointLabel` | `(record: Row) => ReactNode` | Config series label | Receives the actual selected native record. |
| `zDimension` | `ScatterSizeDimension<Row>` | — | Explicit raw zero/missing size recovery; no geometry change. |
| `missingValue` | `ReactNode` | `"No data"` | Text for a recovered missing measurement. |
| `axisId` | `string \| number` | `0` | Match a custom X axis ID for native keyboard navigation. |
| `maxWidth` | `number` | `180` | Kind tooltip width bound in pixels. |
| `content` | `ReactElement \| ((props: TooltipRenderProps) => ReactNode)` | Kind Scatter content | Custom content owns dimension rendering. |

</div>

`zDimension` accepts a string key or numeric/missing-value accessor, plus optional `name` and `unit`. Native formatters take precedence. See [Recharts Tooltip](https://recharts.github.io/en-US/api/Tooltip/).

<div className="line-props-scroll" role="region" aria-label="ScatterTooltipContent props" tabIndex={0}>
