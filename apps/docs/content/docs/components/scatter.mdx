## How it works

Native `XAxis` and `YAxis` use latency in milliseconds and acceptance in percent. Each cohort supplies its own points. `seriesKey` identifies a cohort; it does not map x, y or z data. A native `ZAxis` maps count to marker area; this is a bubble composition without a separate BubbleChart export.

Circle and diamond series shapes are paired with matching config icons. `ScatterTooltip` receives `pointLabel` and an explicit `zDimension`. All seven task observations have measured counts. For sparse data, this mapping also preserves zero versus missing; native marker scaling remains separate. Keyboard traversal follows the first registered series in data order, so the table exposes both cohorts. Automatic category paint emphasis is not implemented here.
