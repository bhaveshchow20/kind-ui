## Usage

Start with axes, a grid and one candle series. Add volume, inspection or history controls as needed. Open **Code** above for the complete interactive example.

```tsx title="components/candlestick-example.tsx"
"use client";

import { CandlestickChart } from "@kind-ui/charts";

const data = [
  { time: "2026-10-05", open: 100, high: 112, low: 96, close: 108, volume: 1200 },
  { time: "2026-10-06", open: 108, high: 114, low: 101, close: 104, volume: 900 },
];
const config = {
  price: { label: "Trade OHLC (USD)", color: "#733bff" },
  volume: { label: "Volume (shares)", color: "#733bff" },
};

export function CandlestickExample() {
  return (
    <CandlestickChart
      data={data} config={config} timeMode="business-date" height={320}
      aria-label="Daily trade OHLC in USD with share volume"
      formatPrice={(value) => `$${value.toFixed(2)}`}
      formatVolume={(value) => `${value} shares`}
    >
      <CandlestickChart.Grid vertical={false} />
      <CandlestickChart.XAxis />
      <CandlestickChart.YAxis orientation="right" />
      <CandlestickChart.Series seriesKey="price" rising="#15803d" falling="#be123c" />
      <CandlestickChart.Volume seriesKey="volume" axisProps={{ hide: true }} />
      <CandlestickChart.Crosshair />
      <CandlestickChart.Content />
    </CandlestickChart>
  );
}
```

## Navigate history

Drag the overview handles to choose a range. Zoom, reset and pan share the same window.

```tsx title="History controls"
<CandlestickChart.Controls />
<CandlestickChart.HistoryNavigator />
```

Add these parts inside `CandlestickChart`. The selected overview stays clear; history outside the handles is dimmed and blurred. Time tags appear on hover, drag or keyboard focus.

## Data and time

| Contract | Rule |
| --- | --- |
| Default record | Complete `{ time, open, high, low, close, volume?, state? }`, or explicit `{ time, gap: true, state? }` without OHLC/volume. |
| Custom rows | Typed keys/functions in `accessors` read time, OHLC, volume, gap and state. Generic callbacks retain the original row in `point.original`. |
| Input order | Strictly ascending, unique identities. No sorting, deduplication, sparse rows or inferred observations. Invalid fields throw with paths. |
| Epoch time | Safe integer milliseconds within the JavaScript Date range. |
| Business dates | Calendar-valid `YYYY-MM-DD`, years `0001`–`9999`; numeric coordinates use midnight UTC. Format as session dates. |
| Spacing | Ordinal gives each supplied interval one slot; elapsed preserves time distance. Omitted sessions and holidays are consumer-owned. |
| OHLC | Finite values satisfying `low <= min(open, close) <= max(open, close) <= high`. Partial OHLC is invalid. `state` is metadata. |
| Volume | Finite and nonnegative; missing stays missing, zero stays zero. Price and volume share time coordinates. |
| Gaps | Preserve supplied time slots and table rows; no candle glyph. Keyboard traversal skips them; pointer inspection can expose them. |

## Price scales and bounds

| Contract | Rule |
| --- | --- |
| Autoscale | Full low/high extrema from visible or all records; no forced zero. A constant-price observation receives a nonzero span. |
| Padding | Nonnegative fraction of the linear or logarithmic domain span, applied on each side. |
| Fixed domain | Finite `minimum < maximum`; controls display clipping and bypasses padding. |
| Bounds | Validate every observation and included overlay, including offscreen values. Only computed padding is clipped; observations are never clamped. Fixed domains must fit bounds. |
| Log scale | Positive OHLC, overlay values, domains and bounds. Linear scales permit negative prices. |
| Overlays | Caller-computed values only; missing values remain gaps. `includeInDomain` controls autoscale contribution. |
| References | Clipped to price region. X uses logical indexes in ordinal mode and numeric time coordinates in elapsed mode; references do not extend the domain. |
| Meaning | Consumers supply trade/bid/ask source, price/volume units, tick rules, calculations and calendars. No inferred probability, payout or opposite outcome. |

## Controlled history

Keep feed data in your state and pass a new ordered array for each update. Use `viewport` and `onViewportChange` to control the window; otherwise use `defaultViewport`. Handle feed errors, retries and cleanup in your application.

| Contract | Rule |
| --- | --- |
| Logical viewport | Inclusive fractional `{ from, to }`, clamped to supplied history. Nonempty ranges require finite `from < to`; fit is `-0.5` through `count - 0.5`. Logical indexes apply in both spacing modes. |
| Ownership | Use controlled `viewport` or initial `defaultViewport`; do not combine them or switch ownership during a mount. |
| Replacement/correction | Replace a row while retaining its time identity. Do not mutate existing arrays. |
| Prepend | Preserve the first surviving visible identity. Controlled owners apply the anchored `onViewportChange` result. An atomic data-and-viewport update honors the explicit new range. |
| Append | Historical browsing stays anchored. `followLatest` follows only from the previous latest edge. |
| Selection/removal | Inspection and persistent selection are separate; clearing hover retains selection. Replacements/prepends retain identity. Removing an identity clears it and reports `null`; controlled owners apply that result. |

## Keyboard and accessibility

| Action | Input |
| --- | --- |
| Inspect adjacent / first / last nongap candle | Left / Right / Home / End |
| Select / clear | Enter or Space / Escape |
| Pan | Shift + Left/Right, drag, or focused horizontal wheel |
| Zoom / fit | Plus or Minus / `0`; focused vertical wheel zooms |
| Pointer/touch | Plot hover inspects; primary tap selects. Axes and margins cannot start gestures. Consumer handlers run first and may veto defaults. |
| Series focus | Shared series controls support mark and keyboard activation, pressed state and inactive-series emphasis. |

Content provides a polite readout. Tooltip defaults to `aria-live="off"` when Content is present; use one announcing readout. DataTable shows current observations and optional original metadata.

### Data and viewport helpers

Most applications only need the chart parts above. For custom data or window controls, these helpers use the same validation as the chart. Callbacks retain your original row in `point.original`.

| Helper | Purpose |
| --- | --- |
| `fitCandlestickViewport(count)` | Fit all logical slots. |
| `normalizeCandlestickViewport(viewport, count)` | Validate and clamp a logical range. |
| `panCandlestickViewport(viewport, delta, count)` | Move by logical slots. |
| `zoomCandlestickViewport(viewport, factor, anchor, count)` | Zoom about a logical anchor; `factor > 1` zooms in. |
| `reconcileCandlestickViewport(previous, next, viewport, { followLatest? })` | Preserve a surviving visible identity across immutable history changes. |
| `getCandlestickVisiblePoints(points, viewport, overscan?)` | Slice supplied records without aggregation. |
| `getCandlestickTimeCoordinate(point, index, spacing)` | Get ordinal or elapsed X coordinate. |
| `getCandlestickLogicalCoordinate(points, coordinate, spacing)` | Convert a numeric X coordinate to its fractional logical position. |
| `getCandlestickTimeDomain(points, viewport, spacing)` | Convert the logical window to the numeric time domain. |
| `getCandlestickPriceDomain(points, options?)` | Compute low/high domain with viewport/autoscale, domain, padding, scale, bounds and explicitly included overlay values. |
