## Usage

`CandlestickChart` requires ordered `data`, an explicit `timeMode`, `config`, an accessible name and explicit children. Add only the parts you need. The chart owns shared time coordinates, history and inspection; the consumer owns observations, financial meaning and units.

```tsx title="Composition sketch"
import {
  CandlestickChart, CandlestickSeries, CandlestickXAxis, CandlestickYAxis,
  CandlestickGrid, CandlestickVolume, CandlestickCrosshair, CandlestickContent,
} from "@kind-ui/charts";

<CandlestickChart
  config={config}
  data={data}
  timeMode="business-date"
  height={320}
  aria-label="Daily trade OHLC in USD with share volume"
  formatPrice={(value) => `$${value.toFixed(2)}`}
  formatVolume={(value) => `${value} shares`}
>
  <CandlestickGrid vertical={false} />
  <CandlestickXAxis />
  <CandlestickYAxis orientation="right" />
  <CandlestickSeries seriesKey="price" rising="#15803d" falling="#be123c" />
  <CandlestickVolume seriesKey="volume" axisProps={{ hide: true }} />
  <CandlestickCrosshair />
  <CandlestickContent />
</CandlestickChart>
```

Named parts also appear as `CandlestickChart.Series`, `.XAxis`, `.YAxis`, `.Grid`, `.Volume`, `.Overlay`, `.ReferenceLine`, `.Crosshair`, `.Tooltip`, `.Content` and `.DataTable`. Omitted parts stay absent. Set plot sizing on the root and outer HTML styles, refs and handlers on `frameProps`.

## Observations and time

A standard candle is `{ time, open, high, low, close, volume?, state? }`. A gap is `{ time, gap: true, state? }` and omits OHLC and volume. Gaps contribute time spacing and remain available to pointer inspection and the data table. Missing volume stays missing; zero volume is a supplied observation.

`timeMode="epoch-ms"` accepts safe integer millisecond instants within the JavaScript Date range. `timeMode="business-date"` accepts calendar-valid `YYYY-MM-DD` strings, with years `0001`–`9999`. Business dates identify sessions; their normalized numeric coordinate is midnight UTC. Format them as dates rather than converting them to local instants.

Input order must be strictly ascending with unique identities. The chart never sorts, deduplicates, guesses timestamp units or fills omitted periods. `spacing="ordinal"` gives every supplied interval one slot and compresses omitted dates. `spacing="elapsed"` preserves numeric time distances. Neither mode supplies exchange sessions or holidays.

All OHLC values must be finite and satisfy `low <= min(open, close) <= max(open, close) <= high`. Volume must be finite and nonnegative. Partial OHLC, sparse arrays, invalid dates and invalid accessor results throw errors with field paths. `state` is a caller-defined string; it does not change the observed values.

### Generic records

Use typed row keys or functions for time, prices, volume, gap and state. Omitted accessors use the standard field names. `CandlestickChart<Row>`, callbacks and generic parts retain the original row as `point.original`.

```tsx title="Provider-neutral adaptation"
type Quote = { at: number; firstBid: number; highestBid: number; lowestBid: number; lastBid: number; source: string };

<CandlestickChart<Quote>
  data={quotes}
  timeMode="epoch-ms"
  accessors={{ time: "at", open: "firstBid", high: "highestBid", low: "lowestBid", close: "lastBid" }}
  config={config}
  aria-label="Bid quote OHLC in USD per contract"
>
  <CandlestickXAxis />
  <CandlestickYAxis />
  <CandlestickSeries<Quote> seriesKey="bid" />
  <CandlestickContent<Quote>>
    {(point) => point ? `${point.original.source}: ${point.close}` : "Inspect an interval"}
  </CandlestickContent>
</CandlestickChart>
```

## Price scales and bounds

The default linear price scale includes complete low/high wick extrema and adds five percent padding on each side. It does not force zero into an observed price domain. Negative prices are valid on a linear scale. A single constant observation gets a nonzero display span.

`autoscale="visible"` uses the current viewport; `"all"` uses the complete series. `priceDomain={[minimum, maximum]}` fixes the displayed range. `pricePadding` controls a fraction of the linear span or logarithmic span. `priceBounds` validates every observation and limits computed padding; it never clamps an out-of-bounds observation. Domains and bounds require finite `minimum < maximum`.

`priceScale="log"` requires strictly positive OHLC, contributing overlay values, domains and bounds. A bounded contract can use a linear `[0, 1]` domain in explicitly supplied USD-per-contract units. The chart never infers cents, dollars, payout, probabilities or a complementary outcome.

Trade OHLC, bid OHLC and ask OHLC describe different observations. Label the source and volume unit in the chart name, readout and data alternative. Sampled price history cannot establish true trade extrema or interval volume. Settlement observations belong in labelled annotations unless the caller supplies actual execution OHLC.

## History and immutable updates

A viewport is an inclusive logical range `{ from, to }`, allowing fractional values. Point indexes remain logical coordinates in both spacing modes. A fitted series spans `-0.5` through `count - 0.5`; a nonempty viewport requires finite `from < to`. The chart clamps ranges to available history.

Use `viewport` and `onViewportChange` for controlled history, or `defaultViewport` for an initial uncontrolled window. Do not combine controlled and default props or switch ownership during a mount. Change callbacks include the reason and actual first/last visible times. Consumers can fetch older pages when a window approaches their history edge; networking and pagination stay outside the chart.

Immutable replacement keeps the same `time`; correction replaces an older row independently. Append and prepend new ordered rows without mutating existing arrays. Uncontrolled history preserves the first surviving visible identity when earlier observations arrive. When data changes while a controlled range stays unchanged, the chart reports an anchored range through `onViewportChange`; apply it in the owner. An atomic data-and-viewport update honors the newly supplied explicit range rather than replacing it with an anchored suggestion. `followLatest` follows appends only when the previous viewport was already at the latest edge. Browsing older history stays in place.

```tsx title="Controlled viewport"
const [viewport, setViewport] = useState({ from: 19.5, to: 49.5 });

<CandlestickChart
  data={data} config={config} timeMode="epoch-ms"
  viewport={viewport} onViewportChange={setViewport}
  followLatest aria-label="Trade OHLC history"
>
  {/* Compose axes, Series and inspection parts here. */}
</CandlestickChart>
```

## Volume, overlays and references

`CandlestickVolume` reserves an aligned lower region with its own nonnegative Y axis. Price and volume use identical time coordinates and crosshair inspection. `volumeRatio` sets the reserved fraction of plot height; the default is `0.22`, and valid values are greater than zero and less than `0.5`. A volume region exists only when that part is composed.

`CandlestickOverlay<Row>` reads caller-computed numbers from original rows. Missing values return `null` or `undefined`; `connectNulls` explicitly controls bridging them. `includeInDomain` opts overlay observations into price autoscale. Overlays never calculate moving averages or reconstruct prices. Use `CandlestickReferenceLine` for price levels and labelled settlement/reference observations. References are clipped to the price region and default to `ifOverflow="hidden"`; `"extendDomain"` is unsupported. Select an explicit root domain or contributing overlay when the displayed range must change. In ordinal mode an X reference uses a logical index; in elapsed mode it uses epoch milliseconds or the numeric UTC business-date coordinate.

## Inspection and accessibility

The focusable chart frame provides these controls:

| Action | Input |
| --- | --- |
| Inspect adjacent nongap candles | Left / Right |
| Inspect first / last nongap candle | Home / End |
| Select the inspected identity | Enter / Space |
| Clear transient inspection and selection | Escape |
| Pan history | Shift + Left / Right, pointer drag or horizontal wheel while focused |
| Zoom / fit | Plus / Minus, `0`, or vertical wheel while focused |
| Inspect / select with touch | Touch an interval; tap selects |

Pointer inspection and persistent selection are separate. Clearing hover leaves selection available to readouts. Immutable replacements and prepends retain time identity. Removing the inspected or selected identity clears its state and reports `null`; controlled selection owners apply that removal. Keyboard traversal skips gaps, while pointer inspection and tables expose them.

`CandlestickContent` renders a polite status readout outside the plot. Its child function receives `(point, selection)` and can include `point.original.source`, units or quality metadata. `CandlestickTooltip` uses the same readout contract in a measured floating frame anchored to the inspected candle, with tooltip semantics. The tooltip announces politely when no `CandlestickContent` is composed; it defaults to `aria-live="off"` when Content supplies the announcing readout. Consumer `frameProps` may override these attributes. Its `maxWidth` defaults to `260`; `frameProps.ref` receives the positioned HTML frame. Compose one announcing readout for the chart. `CandlestickDataTable` provides a real current-state table and a `renderMetadata` callback; it does not require reconstructing values from tooltip payloads.

## Loading State

Set `loading` and a source-specific `loadingLabel` while observations are pending. Set `empty` to customize the message for an empty input array. A series of explicit gaps remains a supplied series with no invented candle glyphs.

### Motion

`animate` uses the existing chart-owned Bar/Motion entrance behavior and reduced-motion handling. Immutable updates and history browsing retain the mounted chart; they do not require remounting the root. Default `animate` is `false`. Consumer `LazyMotion` strict contexts remain supported.

### Pure helpers and normalized points

`normalizeCandlestickData<Row>(data, { timeMode, accessors?, priceScale?, priceBounds? })` performs the same validation as the root. Each `CandlestickPoint<Row>` contains `time`, numeric `timeValue`, mode-prefixed `identity`, `original`, `gap`, and supplied OHLC/volume/state values. Epoch milliseconds and business dates remain distinct identities.

| Helper | Purpose |
| --- | --- |
| `fitCandlestickViewport(count)` | Fit all logical slots. |
| `normalizeCandlestickViewport(viewport, count)` | Validate and clamp a logical range. |
| `panCandlestickViewport(viewport, delta, count)` | Move by logical slots. |
| `zoomCandlestickViewport(viewport, factor, anchor, count)` | Zoom about a logical anchor; `factor > 1` zooms in. |
| `reconcileCandlestickViewport(previous, next, viewport, { followLatest? })` | Preserve a surviving visible identity across immutable history changes. |
| `getCandlestickVisiblePoints(points, viewport, overscan?)` | Slice supplied records without aggregation. |
| `getCandlestickTimeCoordinate(point, index, spacing)` | Get ordinal or elapsed X coordinate. |
| `getCandlestickLogicalCoordinate(points, coordinate, spacing)` | Convert a numeric X coordinate to its fractional logical position. |
| `getCandlestickTimeDomain(points, viewport, spacing)` | Convert the logical window to the numeric time domain. |
| `getCandlestickPriceDomain(points, options?)` | Compute low/high domain with viewport/autoscale, domain, padding, scale, bounds and explicitly included overlay values. |

These parts visualize supplied observations. Feed sockets, authentication, caching, exchange calendars, corporate actions, trade reconstruction, exact tick rules and indicator calculations remain consumer responsibilities. See the [chart documentation](https://kindui.dev/charts/docs/) for shared configuration and the [chart collection](https://kindui.dev/charts/) for other families.
