## Installation

```bash tab="shadcn"
npx shadcn@latest add @kind-ui/scatter-chart
```

```bash tab="npm"
npm install @kind-ui/charts
```

## Composition

```text
ScatterChart
├── ScatterChart.Background
├── ScatterChart.Grid
├── ScatterChart.XAxis
├── ScatterChart.YAxis
├── ScatterChart.ZAxis
├── ScatterChart.Series
├── ScatterChart.Tooltip
└── ScatterChart.Legend
```

`ScatterChart` holds the series config and the accessible name, and draws only the parts you add. Unlike the other cartesian charts, each `ScatterChart.Series` takes its own `data`. The tooltip and legend read their labels and colors from `config`.

## Usage

### Series and Axes

Both axes are numeric: give each one `type="number"` and the `dataKey` it reads from the points. `name` and `unit` label the value in the tooltip.

Add one `ScatterChart.Series` per group, with its points in `data` and its `config` key in `seriesKey`. Set `shape` to tell groups apart without color: `circle` (the default), `cross`, `diamond`, `square`, `star`, `triangle` or `wye`. Give the `config` entry the same `legendShape` so the legend matches.

`ScatterChart.Tooltip` titles each point with its series label. Pass `pointLabel` to title it from the point's own record instead, like the task name above.

### Bubble Size

Add `ScatterChart.ZAxis` to size each point by a third measure. Its `range` sets the smallest and largest bubble area, in square pixels:

Recharts draws zero and missing sizes at the smallest area and leaves them out of the tooltip. Pass the same key to the tooltip's `zDimension` to show them, as `0k` and `missingValue` ("No data" by default).

### Legend and Keyboard

Pressing a legend item highlights its points and dims the others. Press it again, or press Escape, to clear it. To hide and show series from the legend instead, see [Legend](../building-blocks/legend.mdx).

Focus the chart and press the left and right arrow keys to move through the points of the first series, which shows the tooltip, and Escape to dismiss it. Hover reaches every series.

Set `material="clay"` or `"glow"` on a series for a finish on the built-in shapes; see [Materials](../guides/materials.mdx).

### Motion

Pass `animate` to fade the points in when the chart mounts, or `animate={{ revealDurationMs: 900 }}` to change the duration. Scatter charts don't animate by default. When the reader prefers reduced motion, points appear without fading in. See [Motion](../guides/motion.mdx).

### Loading

Set `loading` while the data is on its way. The chart keeps its size and shows placeholder points, which hold still when the reader prefers reduced motion. Screen readers hear `loadingLabel` ("Loading chart" by default):

```tsx
<ScatterChart loading={isPending} loadingLabel="Loading latency" {...props}>
```
