## Website analytics

Kind UI uses Cloudflare Web Analytics to understand page views, visits, referrals and website performance. It runs on the production gallery and documentation, with no analytics popup or preference control.

Cloudflare Web Analytics does not use cookies or localStorage to collect usage metrics, and does not fingerprint individual visitors. See [Cloudflare Web Analytics privacy information](https://www.cloudflare.com/web-analytics/).

The site does not load Google Analytics or advertising trackers. Local development and preview deployments omit the analytics beacon.

## Chart package

The `@kind-ui/charts` package contains no website analytics integration. Installing it in your application does not enable Kind UI tracking.

For privacy questions, contact the maintainer through the [Kind UI GitHub repository](https://github.com/bhaveshchow20/kind-ui).
