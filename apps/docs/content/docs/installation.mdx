## Installation

Start with a React project. CLI and Manual install the same editable component, backed by `@kind-ui/charts@0.4.0`.

<ChartInstallation name="line-chart" />

## Usage

```tsx title="Dashboard.tsx"
import { LineChart } from "@/components/charts/line-chart";

const data = [{ month: "Jan", sales: 120 }, { month: "Feb", sales: 180 }];
const config = { sales: { label: "Sales", color: "#733bff" } };

export function Dashboard() {
  return <LineChart data={data} config={config} xDataKey="month" aria-label="Monthly sales" />;
}
```

Change the caller's data, labels and colors. Keep a meaningful chart name and an accurate text or table alternative beside your chart.

## npm core

For direct npm usage, install the package and supported peers:

```sh
npm install @kind-ui/charts@0.4.0 react@^19.3.0 react-dom@^19.3.0 recharts@^3.10.1 motion@^13.4.6
```

Import CSS once at your application entry or Next.js root layout:

```tsx
import "@kind-ui/charts/styles.css";
import * as Chart from "@kind-ui/charts";
```

Use the same public plot parts with your own composition. Configured `LineChart`, `HeatmapChart` and `ActivityRings` already supply their context; do not add another `Root`. In Next.js, place interactive chart components behind a `"use client"` boundary.

## Upgrading

The registry requests core 0.4.0 and the CLI currently saves a `^0.4.0` npm range. Keep your lockfile and check the resolved version before updating. Review local source edits before reinstalling; the CLI can prompt before overwriting shared files.

Review the [changelog](https://github.com/bhaveshchow20/kind-ui/blob/main/packages/charts/CHANGELOG.md), then typecheck, build and check keyboard interaction, tooltips, loading, mobile sizing and reduced motion. The old named demo URLs remain available for compatibility but are absent from the current registry index.

See [Troubleshooting](/docs/guides/troubleshooting/) if a chart is blank or an import fails.
