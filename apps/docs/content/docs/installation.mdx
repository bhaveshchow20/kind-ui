Install the ESM package in an existing React project. npm resolves its required peers.

<Steps>
<Step>

### Install the package

```sh
npm install @kind-ui/charts
```

Kind UI charts supports React/React DOM `^19.3.0`, Recharts `^3.10.1` and Motion `^13.4.6`. Motion is required even with animation off.

</Step>
<Step>

### Configure Tailwind CSS v4

Kind UI uses Tailwind v4 utility classes. Add the installed chart package to your
Tailwind sources; the `@source` path is relative to your CSS file.

<Tabs items={["React", "Next.js"]}>
<Tab value="React">

For a Vite app, install the Tailwind integration:

```sh
npm install -D tailwindcss @tailwindcss/vite
```

```ts title="vite.config.ts"
import { defineConfig } from "vite";
import tailwindcss from "@tailwindcss/vite";

export default defineConfig({ plugins: [tailwindcss()] });
```

```css title="src/app.css"
@import "tailwindcss";
@source "../node_modules/@kind-ui/charts/dist";
```

Import your CSS once at your application entry:

```tsx title="src/main.tsx"
import "./app.css";
```

</Tab>
<Tab value="Next.js">

Install the Tailwind PostCSS integration:

```sh
npm install -D tailwindcss @tailwindcss/postcss
```

```js title="postcss.config.mjs"
export default { plugins: { "@tailwindcss/postcss": {} } };
```

```css title="app/globals.css"
@import "tailwindcss";
@source "../node_modules/@kind-ui/charts/dist";
```

Import your CSS in the root layout:

```tsx title="app/layout.tsx"
import "./globals.css";
```

Put interactive chart components behind a client boundary:

```tsx title="Chart.tsx"
"use client";
import * as Chart from "@kind-ui/charts";
```

</Tab>
</Tabs>

If Tailwind v4 is already configured, add only the `@source` directive. Adjust the
relative path when your CSS lives elsewhere. There is no package stylesheet to import.

</Step>
<Step>

### Build your first chart

Open **Code**, copy the component into `MonthlyVisitorsChart.tsx`, and keep the Tailwind setup above. The example includes the data and chart name.

<ChartExample id="line-start" />

#### Render the chart

```tsx title="Dashboard.tsx"
import { MonthlyVisitorsChart } from "./MonthlyVisitorsChart";

export function Dashboard() {
  return <MonthlyVisitorsChart />;
}
```

Run your app. You will see four months of visitors; inspect a point to read its value.

</Step>
</Steps>

## Use your own data

In the copied component, replace `data` with your observations. Keep `period` as the x-axis field and `visitors` as a number, or change `xDataKey` and the config key together.

Change the config label and color to match your measure. Update the chart name and text alternative too.

## Composition

Configured `LineChart` supplies context, sizing and plot parts. Do not wrap it in `Root`.

Other families use their own composition. Start with their complete examples:

| Your task | Next example |
| --- | --- |
| Compare categories | [Bar](/docs/components/bar/) |
| Show bounded progress | [Radial and Activity Rings](/docs/components/radial/) |
| Show relationships | [Scatter](/docs/components/scatter/) |
| Trace flows | [Sankey](/docs/components/sankey/) |

Use [Line composition](/docs/components/line/#compose-plot-parts) when you need custom axes or series. See [Accessibility](/docs/guides/accessibility/) before embedding a chart in your product.

## Public imports

```tsx
import * as Chart from "@kind-ui/charts";
```

Use the documented exports. There is no `@kind-ui/charts/motion` entry.

## Upgrading

Review the [changelog](https://github.com/bhaveshchow20/kind-ui/blob/main/packages/charts/CHANGELOG.md), then typecheck and build your app. Check sizing, keyboard access, controlled visibility, missing/zero values and reduced motion. Keep your data alternative current.

See [Troubleshooting](/docs/guides/troubleshooting/) if the chart is blank or an import fails.
