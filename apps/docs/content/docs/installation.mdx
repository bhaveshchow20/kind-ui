title: Installation

---

Set up Kind UI charts in an existing React 19 project.

<Steps>
<Step>

### Install Motion and Recharts

```sh
npm install motion recharts
```

Motion is required even when chart animation is off. Kind UI supports React and React DOM `^19.3.0`.

</Step>
<Step>

### Install the package

```sh
npm install @kind-ui/charts
```

</Step>
<Step>

### Configure Tailwind CSS v4

Kind UI uses Tailwind v4 utility classes. If Tailwind v4 is already configured,
add this one line to your existing CSS entry:

```css
@source "../node_modules/@kind-ui/charts/dist";
```

Tailwind skips `node_modules` by default. This directive includes the chart
classes in your generated CSS. Its path is relative to the CSS file: use
`../node_modules/...` from `src/app.css` or `app/globals.css`, and
`../../node_modules/...` from `src/app/globals.css`.

If you have not set up Tailwind yet, follow the steps for your app below.

<Tabs items={["React", "Next.js"]}>
<Tab value="React">

For a Vite app, install the Tailwind integration:

```sh
npm install -D tailwindcss @tailwindcss/vite
```

```ts title="vite.config.ts"
import { defineConfig } from "vite";
import tailwindcss from "@tailwindcss/vite";

export default defineConfig({ plugins: [tailwindcss()] });
```

```css title="src/app.css"
@import "tailwindcss";
@source "../node_modules/@kind-ui/charts/dist";
```

Import your CSS once at your application entry:

```tsx title="src/main.tsx"
import "./app.css";
```

</Tab>
<Tab value="Next.js">

Install the Tailwind PostCSS integration:

```sh
npm install -D tailwindcss @tailwindcss/postcss
```

```js title="postcss.config.mjs"
export default { plugins: { "@tailwindcss/postcss": {} } };
```

```css title="app/globals.css"
@import "tailwindcss";
@source "../node_modules/@kind-ui/charts/dist";
```

Import your CSS in the root layout:

```tsx title="app/layout.tsx"
import "./globals.css";
```

Put interactive chart components behind a client boundary:

```tsx title="Chart.tsx"
"use client";
import { LineChart } from "@kind-ui/charts";
```

</Tab>
</Tabs>

There is no package stylesheet to import.

</Step>
</Steps>

See [Troubleshooting](/docs/guides/troubleshooting/) if installation or styling fails.
