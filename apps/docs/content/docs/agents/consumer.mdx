1. Read [installation](/docs/start/installation/) and the exact example Markdown from [llms.txt](/llms.txt). This initial Site is owner-private; anonymous public retrieval is not established.
2. Download the complete example. Use the included pinned tarball while the package is unpublished. Do not reach into repository implementation paths.
3. Apply the copied prompt's selected settings file. Keep chart imports, native engine imports and stylesheet setup explicit.
4. Typecheck/build the consumer, then verify legend/filter behavior, zero/missing values, sizing, keyboard access and the data alternative.
5. Report failures with evidence. Separate packaging, API, docs, runtime and agent mistakes.

The page Copy prompt includes persistent control/visibility settings and acceptance criteria. Transient pointer or keyboard emphasis is not copied as an initial state. Copy Markdown contains the canonical default consumer files and generated public types. Copy prompt and Download example carry the selected settings; it does not dump unresolved MDX or repository internals.

## Reader and contributor instructions

This guide is for package consumers. Repository `AGENTS.md` governs contributors, source changes and release boundaries. A docs build or passing consumer does not authorize npm publication, a main merge or a public audience change.
