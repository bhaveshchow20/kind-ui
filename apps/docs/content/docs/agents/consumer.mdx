## Build a chart

- Import components from `@kind-ui/charts` and its stylesheet once at the application entry.
- Use configured `LineChart` for Root and sizing defaults. Area and Bar use explicit composition.
- Keep data, units, domains and visibility state in your application.
- Include a chart name and complete data alternative.

## Try these prompts

- “Build a weekly tasks line chart with @kind-ui/charts. Include zero observations and a complete accessible data table.”
- “Compare signed revenue by category using BarChart. Keep visibility controlled by application state and check keyboard access.”
- “Adapt the documented Area composition to our app's colors. Preserve missing-value gaps and reduced-motion behavior.”

## Verify

Typecheck and build the consumer. Inspect mobile layout, keyboard access, legend toggles, missing and zero values, contrast and reduced motion.
