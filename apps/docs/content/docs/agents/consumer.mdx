## Consumer skill

```sh
npx skills add bhaveshchow20/kind-ui --skill kind-ui-charts
```

The skill covers chart choice, installation and composition. It is separate from
repository maintainer instructions in `.agents/skills`.

Start with [installation](/docs/start/installation/), then use [llms.txt](/llms.txt)
to retrieve canonical family Markdown. [llms-full.txt](/llms-full.txt) contains the
same pages, complete consumer code and public API tables. Copy prompt follows
the selected example; Copy Markdown contains its canonical default.

## shadcn MCP

Use the [official shadcn MCP setup](https://ui.shadcn.com/docs/mcp) for your client.
For Claude Code, run:

```sh
npx shadcn@latest mcp init --client claude
```

For Codex, add the official server to `~/.codex/config.toml` and restart Codex:

```toml
[mcp_servers.shadcn]
command = "npx"
args = ["shadcn@latest", "mcp"]
```

Merge this mapping into the existing `components.json`, preserving aliases,
style settings and other registries:

```json
{
  "registries": {
    "@kindui": "https://raw.githubusercontent.com/bhaveshchow20/kind-ui/main/apps/docs/public/r/{name}.json"
  }
}
```

The namespace gives MCP and the CLI the same items: `line-chart`, `bar-chart`,
`area-chart` and `charts-dashboard`. CLI installation also works:

```sh
npx shadcn@latest add @kindui/line-chart
```

Review existing-file changes with `--diff`; use `--overwrite` when replacing
those files is intended. Read the [namespace documentation](https://ui.shadcn.com/docs/registry/namespace)
for registry configuration.

## Ownership and verification

The npm package supplies usable, design-neutral charts and shared interaction,
visibility, motion and accessibility behavior. Registry items supply editable
art direction and dashboard composition over public exports. App-specific filters
may stay in the application; reusable chart behavior stays in npm.

Import public components and the stylesheet. Configured `LineChart` owns Root and
sizing defaults; Area and Bar use explicit composition. Provide chart names and
complete data alternatives. Typecheck/build the consumer and inspect mobile
layout, keyboard behavior, legend toggles, missing/zero values and reduced motion.
