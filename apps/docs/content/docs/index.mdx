Charts has thirteen chart families, from lines and bars to Sankey flows and activity rings. Each chart is a family root like `LineChart` that holds your data, plus the parts you choose to show: axes, grid, series, tooltip and legend. Recharts draws the geometry and Motion animates it, so every Recharts prop still works. Keyboard inspection, legend highlighting, loading states and reduced motion come built in.

## Install with the shadcn CLI

Add the `@kind-ui` registry to your `components.json`:

```json title="components.json"
{
  "registries": {
    "@kind-ui": "https://kindui.dev/r/{name}.json"
  }
}
```

Then add a chart by name. Each chart page lists its item:

```bash
npx shadcn@latest add @kind-ui/line-chart
```

The item copies an editable chart into your components, installs `@kind-ui/charts`, and adds an `@source` for the package to your stylesheet so Tailwind picks up its classes.

## Install with npm

```bash
npm install @kind-ui/charts motion recharts
```

The package needs React 19 and Tailwind CSS v4. Add it to the stylesheet that imports Tailwind; the path is relative to that file:

```css title="app/globals.css"
@import "tailwindcss";
@source "../node_modules/@kind-ui/charts/dist";
```

In Next.js, put charts in a client component (start the file with `"use client"`). Parts like `LineChart.XAxis` are properties of a client component, so a server component can't reach them.

## Your First Chart

Pass rows as `data`, name each series in `config`, give the chart an accessible name, and add the parts you want:

```tsx
import { LineChart, type SeriesConfig } from "@kind-ui/charts";

const data = [
  { day: "Mon", tasks: 4 },
  { day: "Tue", tasks: 12 },
  { day: "Wed", tasks: 8 },
];

const config = {
  tasks: { label: "Tasks", color: "#3659b8" },
} satisfies SeriesConfig;

export function TasksChart() {
  return (
    <LineChart data={data} config={config} aria-label="Tasks by day">
      <LineChart.XAxis dataKey="day" />
      <LineChart.YAxis />
      <LineChart.Series dataKey="tasks" />
      <LineChart.Tooltip />
    </LineChart>
  );
}
```

## Theme

Charts read the shadcn theme variables `--foreground`, `--border`, `--muted`, `--muted-foreground`, `--popover`, `--popover-foreground` and `--radius`, so they match the rest of your app. Series colors come from `config`; pass `{ light, dark }` to set one per color scheme.
