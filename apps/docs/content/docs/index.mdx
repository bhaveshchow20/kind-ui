Kind UI provides chart frames, marks, tooltips, legends and visual finishes. Your application owns data, axes, geometry and state.

**This is an unpublished preview.** The examples use a pinned package tarball from source `aa7fe56`. A registry installation command will be added after an authorized release.

## Start with a complete example

- [Combo](/docs/components/combo/): area, bar and line on two native axes.
- [Filtered donut](/docs/components/donut/): category filtering with an included total and shares.
- [Installation](/docs/start/installation/): package status, peer versions and styles.

Every example includes source, setup files, a data alternative and a downloadable consumer. Preview settings are included in copied prompts and downloaded examples.

## Learn the boundaries

[Identity and visibility](/docs/concepts/identity/) explains `dataKey`, `seriesKey`, config and category ownership. [Composition](/docs/concepts/composition/) shows which imports belong to Kind UI and which belong to Recharts. [Public reference](/docs/reference/core/) contains generated prop tables.

For agents, start with the [consumer guide](/docs/agents/consumer/) and [llms.txt](/llms.txt). The separate [showcase](https://kind-ui-charts.angrypirate20.chatgpt.site) demonstrates visual possibilities.
