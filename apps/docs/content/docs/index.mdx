Build charts with reusable components, expressive materials and motion. Keep control of your data, styling and interactions.

Start with [installation](/docs/installation/) and [Quickstart](/docs/quickstart/), then choose a [chart](/docs/components/line/). Each component page includes a live preview, complete code and an API reference.

## Explore

- [Identity and colors](/docs/concepts/identity/): labels, colors and stable series keys.
- [Materials](/docs/guides/materials/): plain, paper, clay and glow finishes.
- [Motion](/docs/guides/motion/): entrances and custom animation.
- [Accessibility](/docs/guides/accessibility/): keyboard access and data alternatives.

For AI-assisted development, use the [consumer guide](/docs/agents/consumer/) and [llms.txt](/llms.txt).
