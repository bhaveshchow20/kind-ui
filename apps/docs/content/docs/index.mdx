Compose charts with public React components. Start with [Quickstart](/docs/start/quickstart/), then explore the [Components](/docs/components/line/).

These examples use the validated, integrated `0.1.0` release candidate from <PackageSource />. The package remains unpublished; registry installation has not been verified. Check [installation](/docs/start/installation/) and [artifact provenance](/package-provenance.json) before reproducing a result.

## Start here

- [Quickstart](/docs/start/quickstart/): chart → sizing → colors → tooltip and legend → motion → composition.
- [Identity and colors](/docs/concepts/identity/): measured fields, stable keys and metadata.
- [Motion](/docs/guides/motion/): family defaults, supported options and custom choreography.

Each Components page includes Preview, Usage, complete Code and API tables. Copy prompt follows the selected example and exact artifact. Provide a [data alternative](/docs/guides/accessibility/) when embedding a chart.

For agents, start with the [consumer guide](/docs/agents/consumer/) and [llms.txt](/llms.txt).
