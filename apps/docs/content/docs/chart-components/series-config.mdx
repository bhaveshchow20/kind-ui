`SeriesConfig` maps stable series or category keys to labels, colors and optional formatting. Pass it to [Root](/docs/chart-components/root/) or directly to a configured [LineChart](/docs/components/line/).

Revenue and Target share labels, colors, and dollar formatting through their config entries.

<ChartExample id="line-comparison" />

## Usage

```tsx title="config.ts"
import type { SeriesConfig } from "@kind-ui/charts";

export const config = {
  visitors: {
    label: "Visitors",
    color: "#733bff",
    formatValue: (value) =>
      typeof value === "number" ? value.toLocaleString("en-US") : String(value),
  },
  subscribers: {
    label: "Subscribers",
    color: "#1c9d8f",
  },
} satisfies SeriesConfig;
```

Use the same keys in `dataKey` or `seriesKey`. For category charts, match the category identity instead of the measured value. See [Identity and colors](/docs/concepts/identity/) for accessor and category examples.

Keys must start with a letter and contain only letters, numbers, underscores or hyphens.

Each entry requires `color`. When `label` is omitted, keys such as `monthlyVisitors` become “Monthly visitors”. Set an explicit label for your preferred wording. The legend follows config order; explicit series paint and tooltip formatters override config defaults.

## Theme colors and series patterns

Use gradient stops or light/dark colors in the same config. Set `color-scheme` on the chart's host to select the theme.

```tsx
import type { SeriesConfig } from "@kind-ui/charts";

const config = {
  visitors: {
    label: "Visitors",
    color: { light: ["#733bff", "#a78bfa"], dark: ["#a78bfa", "#ddd6fe"] },
  },
} satisfies SeriesConfig;
```

Configured patterns supply Bar/Area fills and legend swatches. See [Bar patterns](/docs/components/bar/#series-patterns) for a working example.

## CSS colors and contrast

`Root` exposes colors as `--color-<key>`; gradient colors use the first stop for this variable. Import `@kind-ui/charts/styles.css` to include the default styling.

<Callout type="info">
Use nonempty color strings and gradient arrays. Choose colors with sufficient contrast in both themes.
</Callout>
