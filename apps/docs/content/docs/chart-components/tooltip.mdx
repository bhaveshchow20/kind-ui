`Tooltip` uses [series metadata](/docs/chart-components/series-config/) and stays within the plot bounds. Add it inside the chart, within [Root](/docs/chart-components/root/).

Inspect a daily response time to see Tooltip display the configured label and milliseconds.

<ChartExample id="line-markers" />

## Usage

```tsx
<Chart.Tooltip />
```

The tooltip uses configured labels, colors and value formatters, and excludes hidden series. Press Escape to dismiss inspection. Keyboard inspection support varies by chart family.

## Custom content

Use `TooltipContent` to keep Kind's labels and formatting in a custom content callback. Pass the complete callback payload through its `tooltip` prop.

```tsx
<Chart.Tooltip
  content={(tooltip) => (
    <Chart.TooltipContent tooltip={tooltip} indicator="dot" hideLabel />
  )}
/>
```

Use `missingValue` for absent values. No content appears when every visible entry is missing.
