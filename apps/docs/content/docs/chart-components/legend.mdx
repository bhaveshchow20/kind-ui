`Legend` reads labels and markers from [Root](/docs/chart-components/root/). Place it outside the plot's [ResponsiveContainer](/docs/chart-components/responsive-container/).

Toggle Print or Digital to compare library loans with the same legend controls in grouped or stacked views.

<ChartExample id="bar-comparison" />

## Usage

```tsx
<Chart.Root config={config} visibleSeries={visibleSeries} onVisibleSeriesChange={setVisibleSeries}>
  <Chart.Legend />
  {/* ResponsiveContainer and plot */}
</Chart.Root>
```

Enable toggling with `defaultVisibleSeries={Object.keys(config)}`, or controlled visibility and its callback as above. Click an item to toggle its series.

In focus mode, clicking highlights the series instead. Keyboard users can activate items with Enter or Space and reset focus with Escape.

<Callout type="info">
The legend keeps at least one available item visible. Hidden items remain selectable; unavailable items appear as labels. Configure visibility and focus on [Root](/docs/chart-components/root/).
</Callout>

## Markers and content

Use `icon` or `legendShape` in [SeriesConfig](/docs/chart-components/series-config/) to customize markers. Icons take priority; `Legend.hideIcon` uses color swatches. For Scatter, match `legendShape` to `ScatterSeries.shape`.

Customize item content with the render callback. Keep it noninteractive so the legend button remains the single control.

```tsx
<Chart.Legend>
  {({ label, marker, visible, selected, mode }) => (
    <span>
      {marker}{label}
      {mode === "focus" ? (selected ? " (highlighted)" : "") : (visible ? "" : " (hidden)")}
    </span>
  )}
</Chart.Legend>
```
