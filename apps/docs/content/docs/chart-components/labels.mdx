Kind exports Recharts' `LabelList`, `Label` and `Cell` directly. Use them within the chart or series supported by Recharts.

This doughnut chart uses LabelList for shares of the original total and Cell for slice colors.

## LabelList

Nest `LabelList` inside a series. Choose the value with `dataKey` and its placement with `position` and `offset`.

```tsx
<Chart.LineSeries dataKey="orders">
  <Chart.LabelList dataKey="orders" position="top" offset={8} />
</Chart.LineSeries>
```

In radial bars, use `content={<Chart.RadialBarLabel />}` for measured arc text. Keep percentage labels based on the full data when focusing or hiding; visibility does not reallocate the chart.

See [Recharts LabelList](https://recharts.github.io/en-US/api/LabelList/).

## Label

Use `Label` for axis titles or center text; `content` supports custom SVG rendering.

See [Recharts Label](https://recharts.github.io/en-US/api/Label/).

## Cell

Nest `Cell` inside a supported series to set each item's color. Keep Cells in the same order as the series data, including after filtering.

```tsx
<Chart.PieSeries data={data} dataKey="value" nameKey="category">
  {data.map((row) => <Chart.Cell key={row.category} fill={row.color} />)}
</Chart.PieSeries>
```

See [Recharts Cell](https://recharts.github.io/en-US/api/Cell/) for supported props and the chart family's material guidance for custom paint.
