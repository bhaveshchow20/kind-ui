`Root` connects your plot, legend and tooltip to a [series config](/docs/chart-components/series-config/).

Focus Print or Digital to dim its peers while preserving the bars and tooltip values.

<ChartExample id="bar-comparison" />

## Usage

```tsx
import * as Chart from "@kind-ui/charts";

const config = {
  orders: { label: "Orders", color: "#4477aa" },
} satisfies Chart.SeriesConfig;

<Chart.Root config={config} defaultVisibleSeries={Object.keys(config)}>
  <Chart.Legend />
  <Chart.ResponsiveContainer width="100%" height={280}>
    <Chart.BarChart data={[{ day: "Mon", orders: 24 }]} aria-label="Daily orders">
      <Chart.XAxis dataKey="day" />
      <Chart.BarSeries dataKey="orders" />
      <Chart.Tooltip />
    </Chart.BarChart>
  </Chart.ResponsiveContainer>
</Chart.Root>
```

## Visibility

Pass `visibleSeries` to control visibility in your own state. Focus never changes this value. To request hide/show from Legend, explicitly use `interaction={{ kind: "series", mode: "visibility", eligibleKeys: Object.keys(config) }}` and `onVisibleSeriesChange`.

```tsx
import { useState } from "react";

const [visibleSeries, setVisibleSeries] = useState<string[]>(Object.keys(config));

<Chart.Root
  config={config}
  interaction={{ kind: "series", mode: "visibility", eligibleKeys: Object.keys(config) }}
  visibleSeries={visibleSeries}
  onVisibleSeriesChange={setVisibleSeries}
>
  {/* Legend and plot */}
</Chart.Root>
```

For uncontrolled visibility, set `defaultVisibleSeries={Object.keys(config)}`. The default legend focuses and dims; only explicit visibility mode toggles hidden items.

<Callout title="Note">Explicit visibility-mode legend actions keep at least one eligible item visible. Consumer-controlled visibility can still hide every item; provide an empty-result message.</Callout>


## Interaction and eligibility

Focus is the default; it highlights a series without hiding data. Use stable `eligibleKeys` for available identities, including temporarily hidden series.

```tsx
<Chart.Root
  config={config}
  interaction={{
    kind: "series",
    mode: "focus",
    eligibleKeys: Object.keys(config),
    defaultSelected: null,
    markActivation: "matching-legend",
  }}
>
  <Chart.Legend />
  {/* Participating marks and legend share focus */}
</Chart.Root>
```

Use `selected` with `onSelectionChange` for controlled focus, or `defaultSelected` for uncontrolled focus. Activating the same item or pressing Escape clears focus.

`markActivation` defaults to `"matching-legend"` in focus mode, so supported marks share the legend's actions. Set `"none"` to keep marks passive.

<Callout title="Note">Your event handlers run first. Call `event.preventDefault()` or return `false` from `onBeforeInteraction` to cancel the shared action.</Callout>

## Props

`emphasis` defaults to `"auto"`. Set `"none"` to disable Kind emphasis within this root; individual chart families define which marks support it.

Each config key supplies a `--color-{key}` CSS variable for custom marks.

## Loading

Set `loading` on any chart or `ActivityRings` while its data is pending. The chart keeps its size, and `loadingLabel` is announced to screen readers.

```tsx
<Chart.LineChart data={data} config={config} xDataKey="month"
  loading={isPending} loadingLabel="Loading monthly sales"
  aria-label="Monthly sales" />
```

<Callout title="Note">Reduced motion keeps the loading preview still. Show your own message for errors or empty results.</Callout>
