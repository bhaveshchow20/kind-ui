---
title: Identity and colors
description: Match measured values to stable labels, colors, and visibility keys.
---

A value tells you how much; an identity tells you which series or category it
belongs to. Keep identities stable when you reorder, filter, or update data.

| Field | Purpose | Example |
| --- | --- | --- |
| `dataKey` | Read the measured value | `"visitors"` or `(row) => row.count` |
| `seriesKey` | Match a series to its config | `"visitors"` for an accessor series |
| Category ID | Match one category to its config | `"search"` for a slice worth 35 |
| `config` | Assign labels, colors, and formatting | `visitors: { label: "Visitors", color: "#733bff" }` |

## Series

A string `dataKey` usually matches the config key. For a function or numeric
`dataKey`, supply `seriesKey` so formatting and visibility use the same identity.

```tsx
const data = [{ month: "Jan", count: 42 }, { month: "Feb", count: 58 }];
const config = { visitors: { label: "Visitors", color: "#733bff" } };

<Chart.LineChart
  data={data}
  config={config}
  xDataKey="month"
  series={[{ dataKey: (row) => row.count, seriesKey: "visitors" }]}
  aria-label="Monthly visitors"
/>
```

The example reads `count` but uses `visitors` for its label, color, and legend.
See [Root](/docs/chart-components/root/) to control visibility and
[SeriesConfig](/docs/chart-components/series-config/) to format values.

## Category and node colors

Match category IDs to metadata independently of the measured value.

```tsx
const data = [{ id: "search", value: 35 }, { id: "direct", value: 65 }];
const config = {
  search: { label: "Search", color: "#733bff" },
  direct: { label: "Direct", color: "#1c9d8f" },
};

<Chart.PieSeries data={data} dataKey="value" categoryKey="id" />
```

Place the Pie series inside a PieChart and `Root config={config}`. Reordering
these rows keeps Search purple and Direct green.

| Family | Identity and metadata |
| --- | --- |
| [Pie](/docs/components/pie/) | `PieSeries.categoryKey` matches rows to Root config |
| [Radial](/docs/components/radial/) | `RadialBarChart.categoryKey` matches chart rows to Root config |
| [ActivityRings](/docs/components/radial/#activityrings) | Each ring's `key` matches its config; `value` and `domain` describe progress |
| [Sankey](/docs/components/sankey/) | Node IDs match `nodeConfig`; pass the same config to `SankeyLegend` |
| [Heatmap](/docs/components/heatmap/) | Row/column IDs locate cells; a quantitative scale colors their values |

Explicit series paint and per-item Cells can override config colors. Keep legend
metadata consistent with those choices. For category visibility or node focus,
use the family's documented Root interaction binding.

## Inspection and emphasis

Inspecting a value shows its tooltip. Emphasis highlights a mark or series;
visibility hides it. These are separate choices. Family pages show which
interactions their marks support.
