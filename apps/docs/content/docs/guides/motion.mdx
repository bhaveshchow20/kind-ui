---
title: Motion
description: Enable chart entrances and adjust their timing.
---

Set `animate` on the chart to reveal its marks when it appears. Animation is off by default.

## Enable an entrance

Use `true` for the family defaults or `false` for a still chart.

```tsx
import { LineChart } from "@kind-ui/charts";

<LineChart data={data} config={config} animate aria-label="Monthly visitors">
  <LineChart.XAxis dataKey="month" />
  <LineChart.Series dataKey="visitors" />
  <LineChart.Tooltip />
</LineChart>
```

Keep your explicit parts inside the same chart. See [Chart frame](/docs/chart-components/chart/) for sizing and shared controls.

## Family defaults

Entrances reveal the final chart geometry. Data changes finish the current
entrance; they do not interpolate between datasets. Remount a chart to replay
its entrance intentionally.

| Family | Enabled by default | Entrance |
| --- | --- | --- |
| [Line](/docs/components/line/) | No | Line reveal across the plot |
| [Area](/docs/components/area/) | No | Area reveal across the plot |
| [Bar](/docs/components/bar/) | No | Bars reveal from zero, clamped to the numeric domain |
| [Histogram](/docs/components/histogram/) | No | Bar reveal |
| [Waterfall](/docs/components/waterfall/) | No | Range-bar reveal |
| [Box Plot](/docs/components/box-plot/) | No | Reveal of the composed statistical marks |
| [Combo](/docs/components/combo/) | No | Line, Area, and Bar reveals |
| [Pie](/docs/components/pie/) | No | Angular sector reveal |
| [Radar](/docs/components/radar/) | No | Polygon reveal from the center |
| [Radial and ActivityRings](/docs/components/radial/) | No | Directional sector reveal |
| [Scatter](/docs/components/scatter/) | No | Marks fade in place |
| [Sankey](/docs/components/sankey/) | No | Kind link paint flows along fixed paths |
| [Heatmap](/docs/components/heatmap/) | No | Diagonal cell fade |

## Option objects

Tune entrance duration in milliseconds and inspection transitions in seconds.

```tsx
import { type LineAnimation, LineChart } from "@kind-ui/charts";

const animation = {
  revealDurationMs: 600,
  revealEasing: "easeOut",
  hoverTransition: { type: "tween", duration: 0.12 },
} satisfies LineAnimation;

<LineChart data={data} config={config} animate={animation} aria-label="Monthly visitors">
  <LineChart.XAxis dataKey="month" />
  <LineChart.Series dataKey="visitors" />
</LineChart>
```

Line, Area, Bar, Pie, Radar, Radial, and Scatter accept these fields through
their family animation types. Histogram, Waterfall, and Box Plot use
`BarAnimation`.

| Option | Default |
| --- | --- |
| `revealDurationMs` | 1000; Scatter uses 700; Sankey uses 450 |
| `revealEasing` | Cartesian: `[0.25, 0.1, 0.25, 1]`; polar and Scatter: `"easeOut"` |
| `hoverTransition` | Spring with stiffness 210, damping 28, and mass 0.8 |

Combo accepts `lineReveal`, `areaReveal`, and `barReveal` overrides. Set an override
to `false` to skip that family's entrance. Sankey accepts only
`revealDurationMs`; Heatmap accepts only a boolean.

Pie and Radial support `animationDirection="clockwise"` or `"anticlockwise"`.
This changes the entrance direction without changing the final angles.

## Reduced motion

Kind respects live `prefers-reduced-motion` changes. Entrances show final
geometry and inspection movement stops when reduced motion is requested.

`animate={false}` also disables Kind inspection movement. Tooltip digit shuffle
is separate: omit `valueAnimation="shuffle"` when you want still values.

## Custom choreography

For a scene sequence or chart crossfade, disable built-in animation and control
the timing in your application. Custom shapes and tooltip content also own
their motion. Provide a still result for reduced-motion users and retain a
clear [chart name and descriptions](/docs/guides/accessibility/).
