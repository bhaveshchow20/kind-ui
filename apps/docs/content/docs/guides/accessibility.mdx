title: Accessibility
description: Name charts and provide readable values and keyboard access.
---

Give every chart a meaningful name. Include units, zero values and missing observations in labels and tooltips. Documentation examples render the graph without alternative tables.

## Name and describe the chart

Use `aria-label` or `aria-labelledby` for the chart name.

```tsx
import { LineChart } from "@kind-ui/charts";

<LineChart
    data={[{ month: "Jan", visitors: 42 }, { month: "Feb", visitors: 58 }]}
    config={{ visitors: { label: "Visitors", color: "#733bff" } }}
    aria-label="Monthly visitors"
  >
    <LineChart.XAxis dataKey="month" />
    <LineChart.Series dataKey="visitors" />
    <LineChart.Tooltip />
</LineChart>
```

Applications can explicitly add family-specific data views with
[HeatmapChart.DataTable](/docs/components/heatmap/#heatmapdatatable) or
[SankeyChart.Table](/docs/components/sankey/#sankeycharttable) when needed. These optional parts are omitted from the examples.

## Keyboard access

Inspection differs by chart family. Use the family's complete example to keep
its keyboard controls and descriptions together.

| Chart or control | Access |
| --- | --- |
| [Legend](/docs/chart-components/legend/) | Enter or Space toggles eligible series or selects focus; Escape resets focus |
| Cartesian charts and [Pie](/docs/components/pie/) | Native Recharts inspection with `accessibilityLayer`; use meaningful chart labels |
| [Scatter](/docs/components/scatter/) | Native keyboard inspection covers the first series; expose all series in the alternative |
| [Radar](/docs/components/radar/) | Series controls support selection; no arrow-key inspection between spokes |
| [Heatmap](/docs/components/heatmap/) | Arrow keys move between cells; Home/End navigate the grid; Escape dismisses inspection |
| [Sankey](/docs/components/sankey/) | Use link controls or a visible `SankeyChart.Table` inspector for keyboard selection |
| [ActivityRings](/docs/components/radial/) | Built-in descriptions retain original ring values; give the chart a name |

<Callout type="info">
A tooltip does not replace complete data access. Keep keyboard focus visible,
and use labels or patterns alongside colors when color conveys a distinction.
</Callout>

## Motion and loading

Kind respects reduced-motion preferences. Custom renderers must handle their own
motion. See [Motion](/docs/guides/motion/) for still-chart options.

Set `loading` while a request is pending. Only the plot placeholder is visible; chart-owned legends, content and instructions return when ready without resetting selection. Use `loadingLabel` to name that state;
show a separate message for empty results or errors. See
[Chart loading](/docs/chart-components/chart/#loading).

## Check the result

Test the copied example with keyboard navigation and at narrow widths. Check
chart names, focus visibility, units, contrast, missing values, and reduced
motion. Test with your audience's browsers and screen readers; automated browser
checks alone do not establish screen-reader conformance.
