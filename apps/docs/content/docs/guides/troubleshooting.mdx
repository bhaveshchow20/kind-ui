description: Resolve chart installation, sizing, and composition problems.

Find the visible symptom below, then check it against the complete example for
your [chart family](/docs/).

## Installation and sizing

Check public imports, CSS, and the chart's container first.

| Symptom | Action |
| --- | --- |
| Package or import cannot resolve | Follow [Installation](/docs/installation/); import from `@kind-ui/charts`, not its source files |
| Motion import fails | Install the required Motion peer; there is no `@kind-ui/charts/motion` entry |
| Chart appears unstyled | Follow the [Tailwind setup](/docs/installation/#configure-tailwind-css-v4) |
| Chart is blank or has no height | Set a numeric chart `height`, or give percentage sizing a measurable parent; see [Sizing](/docs/chart-components/chart/#sizing) |
| Chart overflows a flex/grid layout | Give its parent `min-width: 0`; check axis-label space and long values |
| Colors overlap between independent hydrated React roots | Assign a distinct React `identifierPrefix` to each root |

## Composition and interaction

Each chart owns its frame and requires explicit parts.

| Symptom | Action |
| --- | --- |
| Chart has no marks or legend | Add explicit family Series and Legend parts; `config` only supplies metadata |
| Chart reports a nested frame | Place each family in its own frame rather than nesting chart families |
| Legend clicks do not change visibility | Focus dims by default. For hide/show, set chart `interaction.mode="visibility"` and pair controlled visibility with its callback, or use `defaultVisibleSeries` |
| Accessor series ignores visibility or metadata | Give it a matching `seriesKey`; see [Identity and colors](/docs/concepts/identity/) |
| Category colors move when rows reorder | Use stable category IDs rather than row positions; see the family example |
| Arrow keys do not inspect every mark | Check the family's [keyboard access](/docs/guides/accessibility/#keyboard-access); retain a complete data alternative |
| Arrow keys stay on the hovered category | Move the pointer out of the plot before entering keyboard inspection |
| Material does not affect a custom mark | Custom shapes, paint, and filters can replace the built-in appearance |
| Entrance stops after an update | Data/layout changes finish the entrance; remount to replay intentionally |
| Copied source shows a different option | Select the desired preview option, then copy again |

## Report a problem

Include the package and peer versions, complete example, and expected and
observed results. Add reproduction commands. For a docs layout issue, include
the page, viewport width, and interaction steps.
