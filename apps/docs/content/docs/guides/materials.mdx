title: Materials
description: Choose Default, Clay, or Glow for supported chart parts.
---

Use Clay for soft relief or Glow for light around marks. Leave the prop unset
for Default appearance. Choose the finish on the chart part you want to style.

## Choose the prop

Most series use `material`. Sankey uses `finish` for Clay and Glow.

| Chart part | Default | Clay | Glow |
| --- | --- | --- | --- |
| [Line](/docs/components/line/), [Area](/docs/components/area/), [Bar](/docs/components/bar/) series | Omit `material` | `material="clay"` | `material="glow"` |
| [Pie](/docs/components/pie/), [Radar](/docs/components/radar/), [Radial](/docs/components/radial/), [Scatter](/docs/components/scatter/) series | Omit `material` | `material="clay"` | `material="glow"` |
| [HeatmapGrid](/docs/components/heatmap/) | Omit `material` | `material="clay"` | `material="glow"` |
| [Sankey nodes and links](/docs/components/sankey/) | Omit `finish` | `finish="clay"` | `finish="glow"` |

Histogram, Waterfall, Box Plot, and Combo examples use their documented series
parts. Open a family page to compare its live material previews.

Set the finish on the series in your existing Bar composition:

```tsx
import { BarChart } from "@kind-ui/charts";

<BarChart.Series dataKey="orders" material="clay" />
```

For Sankey, set it in the node and link renderers:

```tsx
import { SankeyChart } from "@kind-ui/charts";

<SankeyChart config={nodeConfig} data={flowData} aria-label="Energy flows">
  <SankeyChart.Nodes render={(props) => <SankeyChart.Node {...props} finish="glow" />} />
  <SankeyChart.Links render={(props) => <SankeyChart.Link {...props} finish="glow" />} />
</SankeyChart>
```

<Callout type="info">
Sankey's `material="solid"` or `"gradient"` chooses link paint separately from
`finish`. Custom shapes and filters can replace the built-in appearance.
</Callout>

Materials keep values and geometry unchanged. Check contrast in both themes and
leave room for effects near plot edges. See [Motion](/docs/guides/motion/) to
animate the chart independently.
