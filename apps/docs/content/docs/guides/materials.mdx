---
title: Materials
description: Add Clay or Glow while preserving native chart geometry.
---

Clay (`"clay"`) adds soft relief. Glow (`"glow"`) adds decorative light. Default omits the prop and retains native paint; it is not a material.

| Chart parts | Prop |
| --- | --- |
| Cartesian and polar series | `material` |
| Configured Line | `material` on `LineChart` |
| Heatmap cells | `material` on `HeatmapGrid` |
| Sankey nodes and links | `finish`; independent of solid/gradient `material` |

Family pages show supported parts and complete examples. Custom shapes, explicit filters and native paint retain their documented ownership. Materials preserve values and geometry; motion is independent.

Compare dense marks, missing/zero values, narrow layouts and dark mode. Keep labels, contrast and a readable data alternative. Plot clipping may trim exterior effects; filters add rendering work.
