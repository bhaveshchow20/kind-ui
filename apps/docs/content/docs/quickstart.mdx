## Trends with Line

Configured `LineChart` supplies context, responsive sizing, axes and series. This convenience API belongs to Line; other families use their documented composition.

```tsx title="VisitorTrend.tsx"
"use client";
import * as Chart from "@kind-ui/charts";
import "@kind-ui/charts/styles.css";

const data = [{ month: "Jan", visitors: 42 }, { month: "Feb", visitors: 58 }];
const config = { visitors: { label: "Visitors", color: "#733bff" } };

export function VisitorTrend() {
  return <figure>
    <Chart.LineChart data={data} config={config} xDataKey="month" height={240}
      aria-label="Monthly visitors" />
    <figcaption>January: 42 visitors. February: 58 visitors.</figcaption>
  </figure>;
}
```

## Comparisons with Bar

Explicit composition puts metadata on `Root`, sizing on `ResponsiveContainer`, and geometry on the chart and series.

```tsx title="WeeklyOrders.tsx"
"use client";
import * as Chart from "@kind-ui/charts";
import "@kind-ui/charts/styles.css";

const data = [{ day: "Mon", orders: 24 }, { day: "Tue", orders: 36 }];
const config = { orders: { label: "Orders", color: "#147c68" } };

export function WeeklyOrders() {
  return <figure>
    <Chart.Root config={config}>
      <Chart.ResponsiveContainer width="100%" height={240}>
        <Chart.BarChart data={data} aria-label="Daily orders">
          <Chart.XAxis dataKey="day" />
          <Chart.YAxis />
          <Chart.BarSeries dataKey="orders" />
          <Chart.Tooltip />
        </Chart.BarChart>
      </Chart.ResponsiveContainer>
      <Chart.Legend />
    </Chart.Root>
    <figcaption>Monday: 24 orders. Tuesday: 36 orders.</figcaption>
  </figure>;
}
```

## Pick the family composition

- [Pie](/docs/components/pie/) uses category IDs for slices; [Radial](/docs/components/radial/) also offers `ActivityRings` for completion.
- [Heatmap](/docs/components/heatmap/) composes a native matrix; [Sankey](/docs/components/sankey/) uses nodes and links.
- [Histogram](/docs/components/histogram/) and [Box Plot](/docs/components/box-plot/) show distributions.

Import CSS once. Keep data, domains, units and a readable data alternative in your app. Use a measurable host with `min-width: 0`; `loading` represents pending requests, separately from empty or failed results.

See [composition](/docs/concepts/composition/), [identity and colors](/docs/concepts/identity/), [motion](/docs/guides/motion/) and [accessibility](/docs/guides/accessibility/) for shared contracts. Family pages document their own defaults and limits.
